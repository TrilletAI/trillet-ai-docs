Each tenant needs at least one number for phone calls. You can buy numbers through Trillet, bring your own, or mix both across tenants.

## Endpoints

| Method | Path | Scope |
|---|---|---|
| `GET` | `/partner/v1/tenants/{tenantId}/numbers` | `resources:read` |
| `GET` | `/partner/v1/tenants/{tenantId}/numbers/{numberId}` | `resources:read` |
| `POST` | `/partner/v1/tenants/{tenantId}/numbers` | `numbers:write` |
| `POST` | `/partner/v1/tenants/{tenantId}/numbers/external` | `numbers:write` |
| `DELETE` | `/partner/v1/tenants/{tenantId}/numbers/{numberId}` | `numbers:write` |

## The phone number object

```json
{
  "object": "phone_number",
  "id": "6b0c4e1a9d2f3e4a5b6c7d8e",
  "tenantId": "6a9622d2c1e8f3a4b5d6e7f8",
  "phoneNumber": "+15125550142",
  "provider": "telnyx",
  "type": "local",
  "external": false,
  "status": "active",
  "agentId": null,
  "callFlowId": null,
  "billing": {
    "monthlyPrice": 4.99,
    "nextChargeAt": "2026-12-02T10:20:00.000Z",
    "status": "active"
  },
  "createdAt": "2026-11-02T10:20:00.000Z"
}
```

`billing` is present for numbers bought through Trillet OEM and `null` for your own numbers. `billing.monthlyPrice` is the monthly price in USD, `billing.nextChargeAt` is when the next month is charged, and `billing.status` is `active` or `past_due`.

`GET /numbers/{numberId}` for a number that is not in the tenant returns `404` `number_not_found`.

## Buy a number

Find a number with the standard [available numbers](/v1/api-reference/endpoints/phone-numbers/available-numbers) endpoint, sending the tenant ID in `x-workspace-id`. Then buy it through Trillet OEM, so it is billed to your partner account instead of a card:

```bash
curl -X POST https://api.trillet.ai/partner/v1/tenants/6a9622d2c1e8f3a4b5d6e7f8/numbers \
  -H "Authorization: Bearer tpk_live_..." \
  -H "Idempotency-Key: number-cust_8842-1" \
  -H "Content-Type: application/json" \
  -d '{ "phoneNumber": "+15125550142", "country": "US", "type": "local" }'
```

<ParamField body="phoneNumber" type="string" required>
  The number in E.164 format.
</ParamField>
<ParamField body="country" type="string" required>
  Two-letter country code.
</ParamField>
<ParamField body="type" type="string">
  `local` (default) or `mobile`.
</ParamField>
<ParamField body="addressSid" type="string">
  Regulatory address, for countries that need one.
</ParamField>
<ParamField body="bundleSid" type="string">
  Regulatory bundle, for countries that need one.
</ParamField>

Returns `201` with the number. `Idempotency-Key` is required.

- Each number costs $4.99 per month, whatever its country and type, unless Trillet has agreed a different number price for your account. The price is fixed on the number when you buy it. A change to your account's agreed price applies from each number's next renewal.
- The first month is charged to your account when you buy. After that each number renews monthly on the date it was bought. Renewals are processed daily.
- The `402` below is a check made before the purchase. If the first month's charge then fails after the carrier has sold you the number, the request still returns `201`, with `billing.status: "past_due"`, and no event is sent. Check `billing.status` on the response.
- If a charge cannot be taken, the number keeps working, `billing.status` becomes `past_due`, and the charge is retried daily. Each failed renewal attempt sends a `number.renewal_failed` event, so you get one a day while the number stays past due. Releasing the number is your decision.
- Number charges appear in [usage](/voice-engine/usage-and-billing) as `phone_number_charge`.

| Status | Code | When |
|---|---|---|
| `402` | `insufficient_funds` | Your account cannot pay for the first month, or a [spend cap](/voice-engine/usage-and-billing#spend-caps) has been reached |
| `409` | `tenant_suspended` | Resume the tenant first |
| `400` | `number_purchase_failed` | The carrier refused the purchase, for example the number is taken or a regulatory bundle is needed. The message has the reason. |

## Bring your own numbers

Register a number you or your customer already own. Trillet does not bill these numbers.

<Tabs>
  <Tab title="SIP trunk">

    ```bash
    curl -X POST https://api.trillet.ai/partner/v1/tenants/6a9622d2c1e8f3a4b5d6e7f8/numbers/external \
      -H "Authorization: Bearer tpk_live_..." \
      -H "Idempotency-Key: byo-cust_8842-1" \
      -H "Content-Type: application/json" \
      -d '{
        "phoneNumber": "+15125550199",
        "provider": "sip",
        "credentials": {
          "sipUri": "sip:pbx.example.com",
          "username": "trillet",
          "password": "YOUR_SIP_PASSWORD",
          "ipAddresses": [
            { "id": "carrier-1", "ip": "203.0.113.10", "subnetMask": "32" }
          ]
        }
      }'
    ```

  </Tab>
  <Tab title="Twilio account">

    ```bash
    curl -X POST https://api.trillet.ai/partner/v1/tenants/6a9622d2c1e8f3a4b5d6e7f8/numbers/external \
      -H "Authorization: Bearer tpk_live_..." \
      -H "Idempotency-Key: byo-cust_8842-2" \
      -H "Content-Type: application/json" \
      -d '{
        "phoneNumber": "+15125550188",
        "provider": "twilio",
        "credentials": { "accountSid": "AC...", "authToken": "..." }
      }'
    ```

  </Tab>
</Tabs>

<ParamField body="phoneNumber" type="string" required>
  The number in E.164 format. A number can be registered only once across Trillet.
</ParamField>
<ParamField body="provider" type="string" required>
  `sip` or `twilio`.
</ParamField>
<ParamField body="credentials" type="object" required>
  For `sip`: `sipUri` (where Trillet sends outbound calls), optional `username` and `password`, and optional `ipAddresses` your carrier sends calls from. For `twilio`: `accountSid` and `authToken`.

  Each entry in `ipAddresses` is an object, not a string:

  - `id` (required): any string you choose, unique in the list
  - `ip`: the IPv4 address
  - `subnetMask`: the prefix length as a string, for example `"32"`

  A plain list of IP strings, or an entry without `id`, is refused with `400` `number_registration_failed`.
</ParamField>

Returns `201` with the number. A refused registration returns `400` `number_registration_failed` with the reason.

## Release a number

```bash
curl -X DELETE https://api.trillet.ai/partner/v1/tenants/6a9622d2c1e8f3a4b5d6e7f8/numbers/6b0c4e1a9d2f3e4a5b6c7d8e \
  -H "Authorization: Bearer tpk_live_..."
```

A bought number goes back to the carrier and stops renewing. Your own number is detached from Trillet. Returns `{ "object": "phone_number", "id": "...", "released": true }`.

[Deleting a tenant](/voice-engine/tenants#delete-and-restore) releases all of its numbers the same way.

## Assign a number to an agent

Use the standard [assign phone number to agent](/v1/api-reference/endpoints/telephony/bind-call-to-phoneNumber) endpoint, sending the tenant ID in `x-workspace-id`. It needs `resources:write`. The agent's call flow must be live, so [publish its node flow](/voice-engine/authentication#building-an-agent) first.

```bash
curl -X POST https://api.trillet.ai/v1/api/agents/6a9623aa1b2c3d4e5f6a7b8c/bind/6b0c4e1a9d2f3e4a5b6c7d8e \
  -H "Authorization: Bearer tpk_live_..." \
  -H "x-workspace-id: 6a9622d2c1e8f3a4b5d6e7f8" \
  -H "Content-Type: application/json" \
  -d '{ "recordCalls": true }'
```

Send a JSON body, even an empty `{}`. Optional fields include `recordCalls`, `recordingPublic`, `officeHours`, `metadataTags` and `label`. The number must belong to the tenant. `POST /v1/api/agents/{agentId}/release/{phoneNumberId}` unassigns it.

<Warning>
  `recordingPublic: true` lets anyone who has a call's carrier call SID download that call's recording from a public Trillet endpoint, without a key. Leave it off (the default), and never turn it on for a tenant that handles protected health information.
</Warning>

To change a number's settings later without rebinding it, such as recording, office hours or metadata tags, use the standard [update phone number configuration](/v1/api-reference/endpoints/phone-numbers/update-config) endpoint (`PUT /v1/api/twilio/phone-numbers/{phoneNumberId}/config`).

## Events

Buying or registering a number sends `number.provisioned`, with `phoneNumber` and `provider` in `data`. Releasing one sends `number.released`, and so does deleting its tenant, with `reason: "tenant_deleted"` in `data`. A failed renewal sends `number.renewal_failed`. See [Events](/voice-engine/events).

  A shared partner SIP trunk for all of your tenants is planned.
</Note>
