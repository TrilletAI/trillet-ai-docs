Talk to the assistant the way you would brief a colleague. Say which agent or workspace you mean, what you want changed, and what a good result looks like. The assistant reads your current setup before it changes anything.

These prompts work in ChatGPT, Claude, Claude Code, and any other client connected to Trillet.

## Build an agent

```
Build an inbound receptionist for Harbour Dental. It should answer questions about
opening hours (Mon to Fri 8am to 6pm, Sat 9am to 1pm), take booking requests, and
transfer urgent calls to +61 2 9000 1234. Use a warm Australian female voice.
```

```
Change the welcome message on my Reception agent to "Thanks for calling Harbour Dental,
this is Mia. How can I help?" and make it slightly more patient with interruptions.
```

```
Create a knowledge base called "Harbour Dental FAQ" from https://harbourdental.example/faq
and attach it to the Reception agent.
```

## Test it with a text call

```
Run a text test call with my Reception agent. Play a caller who wants to move their
Thursday appointment to next week and is in a hurry. Tell me where the agent struggled.
```

```
Test the after-hours flow as a caller with a dental emergency. Check that the agent
offers the transfer and doesn't try to book an appointment.
```

<Note>
  A text test call is a real call to your agent over text. It costs a few cents in model usage, and anything the agent does during the call happens for real, such as creating a booking or sending a webhook. Point test calls at test calendars and endpoints where you can.
</Note>

## Review real calls

```
Review the last 20 calls to my Reception agent and list the problems you see,
with the transcript lines that show each one.
```

```
Why did yesterday's 3:42pm call end without a transfer? Show me what the caller asked for.
```

```
How many calls did we take last week, and what was the average call length?
```

## Work across workspaces

```
List my workspaces.
```

```
Switch to Bayview Physiotherapy and show me its agents and phone numbers.
```

## Phone numbers

```
Find a local Sydney number and assign it to the Reception agent. Tell me the
monthly cost before you buy it.
```

```
Which of my numbers aren't assigned to an agent?
```

## Workflows

```
Create a workflow that sends me an SMS summary after every missed after-hours call.
Run a test first and show me the result before you turn it on.
```

```
Why did the "New lead follow-up" workflow fail this morning?
```

## Usage and billing

```
How much have we spent on calls this month, and what is my wallet balance?
```

## Tips for good results

- **Name things.** "The Reception agent in Harbour Dental" is faster and safer than "my agent".
- **Ask it to look first.** "Show me the current prompt, then suggest changes" lets you review before anything changes.
- **Test after every change.** End a build request with "then run a text test call as a new patient".
- **Keep real-world actions explicit.** The assistant asks before it calls a phone, buys a number, runs a workflow, or deletes something. Read the details before you confirm.
