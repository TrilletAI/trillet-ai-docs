## `trillet_delete_knowledge_base`

**Delete knowledge base (or one file)**

Delete an entire knowledge base, or just one file from it when file_key is given. Check usage first (trillet_get_knowledge_base include_usage=true): flows still pointing at a deleted KB lose retrieval. Always confirm with the user; requires confirm=true.

Flags: `writes` `destructive` `asks for confirmation`

Clients that support MCP elicitation show a confirmation form before this tool runs; declining cancels it with no changes. Other clients rely on their own approval prompt and the `confirm` argument.

| --- | --- | --- | --- |

## `trillet_upload_kb_file`

**Upload file to knowledge base**

Upload a file (PDF, DOCX, TXT, MD, CSV, JSON) to a knowledge base from ONE source: file_path (a file on this computer; local installs only), file_url (a public https link), or file_base64 + file_name (the file's bytes, up to 2.5MB). Text is extracted and vector-embedded synchronously in the same request. For plain text, trillet_add_kb_text is simpler. GOTCHA: each knowledge base holds ONE file; uploading replaces the existing file. Use separate knowledge bases for separate documents.

Flags: `writes` `destructive`

### Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `knowledge_base_id` | string | yes |  |
| `file_path` | string | no | Absolute path to a local file (not available on the hosted server) |
| `file_url` | string | no | Public https URL of the file (max 20MB, no redirects) |
| `file_base64` | string | no | Base64 file contents (max 2.5MB); requires file_name |
| `file_name` | string | no | File name with extension, e.g. faq.pdf (required with file_base64, optional with file_url) |
| `workspace_id` | string | no | Run this call in another workspace: its id or its name (see trillet_list_workspaces). Omit to use the default (TRILLET_WORKSPACE_ID, the workspace picked when the connector was approved, or the one set with trillet_switch_workspace). |
