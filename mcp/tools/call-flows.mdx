## `trillet_update_call_flow`

**Update call flow (advanced)**

Partial update of any call-flow fields. Merge semantics (verified): objects DEEP-MERGE (sending settings.callSetting.x preserves siblings), but ARRAYS REPLACE WHOLESALE (webhooks, transfers, postCallAnalysis must be sent complete), and null values are ignored (you cannot null a field). Prefer the dedicated tools for prompt, in-call APIs, and post-call analysis. Top-level settings toggles reachable ONLY through this tool: settings.enableHumanLikeVoiceAndTone (expressive delivery), settings.enableTransferInstructions and settings.enableEndCallInstructions (whether the transfer / end-call prompt blocks are injected; both default on), settings.customerLocation (IANA timezone) and settings.timeContextEnabled (agent knows the current date/time; default on).

## `trillet_update_prompt`

**Update prompt**

Replace a call flow's prompt. The API auto-snapshots a prompt version on every update. Prompt conventions: reference in-call API tools as \{\{realtime_api "tool_name" "var1, var2"\}\} (the canonical token the runtime documents to the model); \{\{key\}\} placeholders are substituted from per-call dynamic variables; do NOT hardcode a scripted greeting in the prompt because the platform welcome message already plays it (a scripted 'Begin with' line causes the agent to greet twice).

Flags: `writes` `destructive` `structured output`

## `trillet_deactivate_drafts`

**Deactivate drafts (use production)**
