## `trillet_purchase_phone_number`

**Purchase phone number (COSTS MONEY)**

Purchase a phone number found via search. Free-plan allocations complete immediately (201 with mode 'free'); otherwise the response contains a Stripe Checkout URL the user must open to pay. Requires confirm=true after the user explicitly approves the purchase. type required except AU; addressSid required outside US/CA/AU/GB.

Flags: `writes` `destructive` `open-world` `billed` `asks for confirmation`

Clients that support MCP elicitation show a confirmation form before this tool runs; declining cancels it with no changes. Other clients rely on their own approval prompt and the `confirm` argument.

## `trillet_register_external_number`

**Register BYO / SIP number**

Register an externally-owned number (bring-your-own Twilio number or a SIP trunk from another carrier, e.g. CommsChannel) so Trillet can route calls on it. provider 'twilio' needs \{accountSid, authToken\}; provider 'sip' needs trunk credentials \{address, username, password, sipType, appendPlus\}. After registering, bind it to an agent like any other number. GOTCHA: DTMF keypresses are known to be dropped on some CommsChannel trunks.

Flags: `writes` `destructive` `open-world` `asks for confirmation`

Clients that support MCP elicitation show a confirmation form before this tool runs; declining cancels it with no changes. Other clients rely on their own approval prompt and the `confirm` argument.

### Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `phone_number` | string | yes | E.164 number being brought over |
| `provider` | "twilio" \| "sip" | yes |  |

| `confirm` | boolean | yes | Must be true. Only set after the user explicitly approved registering this number. |
