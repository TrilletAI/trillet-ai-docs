## `trillet_create_agent`

**Create agent**

Create a new voice agent. ttsModel is REQUIRED by the API (requests without it fail with a 500). Creating an agent usually also creates a linked call flow; check the response's pathway field. Sensible defaults: Rime voice, llmModel "platform-llm".

Flags: `writes`

### Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | yes | Agent display name |
| `llmModel` | string | no | LLM id, e.g. "platform-llm", "gemini-2.5-flash", "gpt-5.2" Default: `"platform-llm"`. |
| `ttsModel` | object | yes | Text-to-speech voice configuration |
| `workspace_id` | string | no | Run this call in another workspace: its id or its name (see trillet_list_workspaces). Omit to use the default (TRILLET_WORKSPACE_ID, the workspace picked when the connector was approved, or the one set with trillet_switch_workspace). |

## `trillet_delete_agent`

**Delete agent**

Delete an agent from the workspace. Unbind its phone numbers first (a bound number stops routing). Always confirm with the user; requires confirm=true. The linked call flow is a separate document and is not deleted.

Flags: `writes` `destructive` `asks for confirmation`

Clients that support MCP elicitation show a confirmation form before this tool runs; declining cancels it with no changes. Other clients rely on their own approval prompt and the `confirm` argument.

### Parameters

| Name | Type | Required | Description |

| `agent_id` | string | yes |  |
