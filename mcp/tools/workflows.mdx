## `trillet_create_workflow`

**Create workflow**

Consult trillet_workflow_reference for step configs, trigger payloads, and template variables before building. GOTCHA: settings.maxRunsPerContact defaults to 1 per 24h and silently skips repeat runs for the same contact; this tool defaults it to 500.
