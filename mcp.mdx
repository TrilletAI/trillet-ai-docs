Trillet runs an official [Model Context Protocol](https://modelcontextprotocol.io) (MCP) server. Connect it to your AI assistant and you can manage your Trillet account by describing what you want in plain language. The assistant reads your setup, makes the changes, and tells you what it did.

The hosted server lives at:

```
https://mcp.trillet.ai/mcp
```

## Choose how to connect

| You use | Connect with | Sign-in | Guide |
|---|---|---|---|
| ChatGPT | Custom MCP connector at `https://mcp.trillet.ai/mcp` | Log in to Trillet | [Connect ChatGPT](/mcp/chatgpt) |
| Claude.ai or Claude Desktop | Custom connector at `https://mcp.trillet.ai/mcp` | Log in to Trillet | [Connect Claude](/mcp/claude) |
| Claude Code | `claude mcp add` with an API key | API key | [Claude Code and other clients](/mcp/claude-code-and-other-clients) |
| Cursor or another MCP client | Hosted server with an API key, or the `@trillet-ai/mcp` npm package | API key | [Claude Code and other clients](/mcp/claude-code-and-other-clients) |

If you use ChatGPT or Claude, use the connector. You sign in with your Trillet login, there is no API key to copy, and you get new tools as soon as Trillet ships them.

## How the connection works

When you connect ChatGPT or Claude, you log in to Trillet and approve access on a consent screen. The connection then acts as you:

- It can work in **every workspace you belong to**. You pick the workspace it starts in, and you can switch at any time by asking.
- It can only do what your Trillet account can do. Trillet checks your workspace membership on every request.
- It can't see or change your password, email, billing details, or API keys.

Read [Security and permissions](/mcp/security) for the full picture, including how to disconnect.

## Work across workspaces

Agencies and teams with several workspaces can move between them in the same conversation. Refer to a workspace by name:

- "List my workspaces."
- "Switch to Acme Clinic."
- "List the agents in Bondi Dental."

The assistant uses `trillet_list_workspaces` and `trillet_switch_workspace` for this. Every tool also accepts a workspace name or id for a single request, so "show yesterday's calls in Harbour Dental" works without switching.

<Note>
  Actions taken through the assistant are real. Calls, phone number purchases, and workflow runs happen for real and are billed to your workspace wallet. The assistant asks you to confirm before it does any of them.
</Note>
