---
title: 'Authentication'
description: 'Authenticate partner API requests with an API key and a workspace id'
---

The partner API base URL is `https://api.trillet.ai`.

Every customer request needs two headers:

- `x-api-key` — your API key
- `x-workspace-id` — the workspace the request applies to

```bash
curl https://api.trillet.ai/v1/api/agents \
  -H "x-api-key: YOUR_API_KEY" \
  -H "x-workspace-id: YOUR_WORKSPACE_ID"
```

<ParamField header="x-api-key" type="string" required>
  Customer API key. Create one with [Create API Key](/v1/api-reference/endpoints/api-keys/create) or from the Trillet settings dashboard.
</ParamField>

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier. Required on every partner API request.
</ParamField>

`Authorization: Bearer` is the dashboard session JWT. It is not how you send a customer API key.

## Obtaining API Keys

Generate an API key under Settings in the dashboard, or with `POST /v1/api/keys`. Each key has its own permissions.

<Note>
  Get your API key from [Trillet Settings Dashboard](https://app.trillet.ai/settings)
</Note>

## Security Best Practices

1. Keep your API keys secure and never expose them in client-side code
2. Rotate your API keys periodically
3. Use different API keys for development and production environments
4. Monitor your API key usage for any suspicious activity
