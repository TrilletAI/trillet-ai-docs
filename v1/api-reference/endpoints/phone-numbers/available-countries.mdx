---
title: "Get Available Countries"
api: "GET /v1/api/twilio/available-countries"
description: "Retrieve a list of countries where phone numbers are available for purchase."
---

<Note>
Your role needs the `phone_number:view` permission. Otherwise the request fails with `403 {"error": "Insufficient permissions"}`.
</Note>

US, CA and AU are always listed. GB is listed only when UK numbers are offered on the platform, so read the response rather than assuming it is there.

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Response Fields

<ResponseField name="countries" type="array">
Array of available countries.

<ResponseField name="code" type="string">
Two-letter country code: `US`, `CA`, `AU`, and `GB` when UK numbers are offered.
</ResponseField>

<ResponseField name="name" type="string">
Full country name.
</ResponseField>

<ResponseField name="available" type="boolean">
Always `true`. Only countries you can buy numbers in are listed.
</ResponseField>

</ResponseField>

<ResponseExample>
```json
{
  "countries": [
    { "code": "US", "name": "United States", "available": true },
    { "code": "CA", "name": "Canada", "available": true },
    { "code": "AU", "name": "Australia", "available": true },
    { "code": "GB", "name": "United Kingdom", "available": true }
  ]
}
```
</ResponseExample>
