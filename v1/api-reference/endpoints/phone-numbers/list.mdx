---
title: "List Phone Numbers"
api: "GET /v1/api/twilio/user-phone-numbers"
description: "Retrieve every phone number in your workspace."
---

Returns all phone numbers in the workspace: numbers bought through Trillet and numbers you brought yourself.

<Note>
Your role needs the `phone_number:view` permission. Otherwise the request fails with `403 {"error": "Insufficient permissions"}`.
</Note>

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Response

A JSON array of phone number objects (not wrapped in an object). An empty workspace returns `[]`.

<ResponseField name="_id" type="string">
The phone number's ID. Use it as `phoneNumberId` in [Get](/v1/api-reference/endpoints/phone-numbers/get-config) and [Update Phone Number Configuration](/v1/api-reference/endpoints/phone-numbers/update-config).
</ResponseField>

<ResponseField name="sid" type="string">
The provider's ID for the number. Use it as `phoneNumberSid` in [Release Phone Number](/v1/api-reference/endpoints/phone-numbers/release).
</ResponseField>

<ResponseField name="phoneNumber" type="string">
The number in E.164 format.
</ResponseField>

<ResponseField name="provider" type="string">
`twilio`, `sip`, `telnyx`, `commschannel` or `whatsapp`.
</ResponseField>

<ResponseField name="type" type="string">
The number type as stored, for example `local` or `mobile`, or `external` for a number you brought yourself.
</ResponseField>

<ResponseField name="isExternal" type="boolean">
`true` for a number you brought yourself.
</ResponseField>

<ResponseField name="country" type="string">
Country code, for example `US` or `AU`.
</ResponseField>

<ResponseField name="status" type="string">
`ready` (no call agent bound yet), `active`, `reserved` or `error`.
</ResponseField>

<ResponseField name="flowType" type="string">
What the number is bound to: `call`, `message`, `both`, or `undefined` (nothing).
</ResponseField>

<ResponseField name="agentId" type="object | null">
The bound call agent as a full object, or `null`.
</ResponseField>

<ResponseField name="pathwayId" type="object | null">
The bound call flow as a full object, or `null`.
</ResponseField>

<ResponseField name="messagePathwayId" type="object | null">
The bound message flow as a full object, or `null`.
</ResponseField>

<ResponseField name="omniFlowAgentId" type="object | null">
The bound message agent as a full object, or `null`.
</ResponseField>

<ResponseField name="recordingEnabled" type="boolean">
Whether calls on this number are recorded.
</ResponseField>

<ResponseField name="officeHours" type="object">
`enabled`, `start`, `end`, `timezone`, `allowedDays` and `blockedDates`. See [Update Phone Number Configuration](/v1/api-reference/endpoints/phone-numbers/update-config).
</ResponseField>

<ResponseField name="transferCallerIdMode" type="string">
`from-transferee` or `from-transferor`.
</ResponseField>

<ResponseField name="metadataTags" type="object">
Key/value tags on the number.
</ResponseField>

<ResponseField name="label" type="string | null">
Optional label.
</ResponseField>

<ResponseField name="monthlyPrice" type="number">
What the number costs per month. `0` for numbers you brought yourself.
</ResponseField>

<ResponseField name="isFreeFromPlan" type="boolean">
`true` when the number came from your plan's free allowance.
</ResponseField>

<ResponseField name="scheduledReleaseAt" type="string | null">
When a paid number whose renewal you cancelled will be removed (ISO 8601), or `null`.
</ResponseField>

<ResponseField name="cancelAtPeriodEnd" type="boolean">
`true` when the number's subscription is set to end at the end of the current period.
</ResponseField>

<ResponseField name="subscriptionStatus" type="string | null">
Status of the number's subscription, or `null` if it has none.
</ResponseField>

<ResponseField name="subscriptionExpiresAt" type="string | null">
When the subscription expires, or `null`.
</ResponseField>

<ResponseField name="workspaceId" type="string">
The workspace the number belongs to.
</ResponseField>

<ResponseField name="createdAt" type="string">
When the number was added (ISO 8601). `updatedAt` is also returned.
</ResponseField>

## Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "Workspace ID is required."}` | No `x-workspace-id` |
| `500` | `{"error": "Workspace ID is required."}` | Any server error. The text is misleading: the header was present |
