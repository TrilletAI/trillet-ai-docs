---
title: 'Get Conversations By Flow ID'
api: 'GET /v1/api/conversations/flow/{flowId}'
description: 'List the conversations for one message flow.'
---

### Headers
<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

### Path Parameters
<ParamField path="flowId" type="string" required>
  The message flow's `_id`. The flow must be in this workspace.
</ParamField>

### Response

An array of conversations (empty if the flow has none). Each conversation has these fields:

<ResponseField name="_id" type="string">
  The conversation's unique identifier.
</ResponseField>

<ResponseField name="workspaceId" type="string">
  The workspace the conversation belongs to.
</ResponseField>

<ResponseField name="pathwayId" type="string">
  The message flow the conversation belongs to. Absent for an inbound SMS that arrived on a number with no message flow.
</ResponseField>

<ResponseField name="agentId" type="string">
  The message flow agent handling the conversation. Absent in the same case as `pathwayId`.
</ResponseField>

<ResponseField name="sessionId" type="string">
  Internal session identifier for the conversation.
</ResponseField>

<ResponseField name="sender" type="string">
  The sender identifier for the conversation, when set.
</ResponseField>

<ResponseField name="customer" type="object">
  The customer in the conversation.
  <Expandable title="properties">
    <ResponseField name="name" type="string">
      The customer's name (`"Unknown"` if never given).
    </ResponseField>
    <ResponseField name="email" type="string">
      The customer's email address (`"Unknown"` for SMS conversations).
    </ResponseField>
    <ResponseField name="phone" type="string">
      The customer's phone number (`"Unknown"` for email conversations).
    </ResponseField>
    <ResponseField name="receiverId" type="string">
      Channel-specific receiver identifier, when set.
    </ResponseField>
    <ResponseField name="senderId" type="string">
      Channel-specific sender identifier, when set.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="messages" type="array">
  The messages in the conversation, oldest first.
  <Expandable title="Message properties">
    <ResponseField name="_id" type="string">
      The message's unique identifier.
    </ResponseField>
    <ResponseField name="direction" type="string">
      `inbound`, `outbound` or `replied`.
    </ResponseField>
    <ResponseField name="sent" type="boolean">
      Whether the message was sent.
    </ResponseField>
    <ResponseField name="subject" type="string">
      Email subject (email conversations only).
    </ResponseField>
    <ResponseField name="message" type="string">
      The message text.
    </ResponseField>
    <ResponseField name="status" type="string">
      `pending`, `auto-approved`, `approved`, `rejected`, `received` or `sent`.
    </ResponseField>
    <ResponseField name="additional_kwargs" type="object">
      Extra data attached to the message. Usually `{}`.
    </ResponseField>
    <ResponseField name="createdAt" type="string">
      When the message was created.
    </ResponseField>
    <ResponseField name="updatedAt" type="string">
      When the message was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="status" type="string">
  `open` or `completed`.
</ResponseField>

<ResponseField name="completedAt" type="string">
  When the conversation was completed, if it has been.
</ResponseField>

<ResponseField name="lastActivity" type="string">
  When the conversation last had activity, when tracked.
</ResponseField>

<ResponseField name="createdAt" type="string">
  When the conversation was created.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  When the conversation was last updated.
</ResponseField>


### Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "Workspace ID is required"}` | No `x-workspace-id` |
| `500` | `{"error": "No conversations found."}` | The flow doesn't exist or isn't in this workspace. This currently returns `500`, not `404` |
| `500` | `{"error": "..."}` | `flowId` isn't a valid ID, or another server error |
