---
title: "List Custom Voices"
api: "GET /v1/api/voices/custom"
description: "Retrieve all custom voices created in your workspace."
---

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Response

A plain array of the custom voices created in this workspace with [Create Custom Voice](/v1/api-reference/endpoints/voices/create). Empty if there are none.

<ResponseField name="id" type="string">
The voice ID. Use it as `ttsModel.voiceId` with provider `cartesia`, and to delete the voice.
</ResponseField>

<ResponseField name="name" type="string">
Name of the custom voice.
</ResponseField>

<ResponseField name="provider" type="string">
Always `cartesia`.
</ResponseField>

<ResponseField name="description" type="string">
Description of the custom voice. Empty string if none was given.
</ResponseField>

<ResponseField name="language" type="string">
Language code for the voice.
</ResponseField>

<ResponseField name="created_at" type="string">
Timestamp when the voice was created.
</ResponseField>

## Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "Workspace ID is required"}` | No `x-workspace-id` |
| `500` | `{"error": "..."}` | The voice catalog couldn't be read |
