---
title: "Search Voices"
api: "GET /v1/api/voices/search"
description: "Search available voices by name, category, gender, accent, age, use case, or provider."
---

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Query Parameters

<ParamField query="name" type="string">
Search voices by name.
</ParamField>

<ParamField query="category" type="string">
Filter by voice category.
</ParamField>

<ParamField query="gender" type="string">
Filter by gender (e.g., "male", "female").
</ParamField>

<ParamField query="accent" type="string">
Filter by accent (e.g., "american", "british", "australian").
</ParamField>

<ParamField query="age" type="string">
Filter by age range (e.g., "young", "middle_aged", "old").
</ParamField>

<ParamField query="useCase" type="string">
Filter by use case (e.g., "conversational", "narration").
</ParamField>

<ParamField query="provider" type="string">
Only search one provider, for example `rime`, `elevenlabs`, `openai`, `openai-live`, `hume`, `cartesia` or `fish`. Aliases are accepted: `trillet` for `rime`, `11labs` for `elevenlabs`, `gpt-live` for `openai-live`. Without it, every provider's catalog is searched, which is slower because most catalogs are fetched live.
</ParamField>

All filters are optional and case-insensitive. `name` also matches a voice's exact `id`; the other text filters match part of the value.

## Response

A plain array of matching voices. Fields vary by provider; these are the ones every result has, plus what Rime (Trillet Voices) returns.

<ResponseField name="voiceId" type="string">
The value to store as `ttsModel.voiceId` on a [call agent](/v1/api-reference/endpoints/agents/call/create). Same as `id`.
</ResponseField>

<ResponseField name="id" type="string">
The provider's voice ID.
</ResponseField>

<ResponseField name="name" type="string">
Display name of the voice.
</ResponseField>

<ResponseField name="provider" type="string">
TTS provider for this voice. Use it as `ttsModel.provider`.
</ResponseField>

<ResponseField name="gender" type="string">
Gender of the voice, where the provider reports one.
</ResponseField>

<ResponseField name="accent" type="string">
Accent of the voice, where the provider reports one.
</ResponseField>

<ResponseField name="language" type="string">
Language code of the voice.
</ResponseField>

<ResponseField name="description" type="string">
Description of the voice characteristics.
</ResponseField>

<ResponseField name="tags" type="string[]">
Descriptive tags (Rime).
</ResponseField>

<ResponseField name="rimeModel" type="string">
Rime only. The model to store as `ttsModel.rimeModel` together with this `voiceId`.
</ResponseField>

<ResponseField name="compatibleModels" type="string[]">
Rime only. Every Rime model this voice runs on.
</ResponseField>

<ResponseField name="settings" type="object">
Rime only. Suggested `speed`, `volume` and `temperature` for the voice.
</ResponseField>
