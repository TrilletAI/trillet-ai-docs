---
title: "Create Custom Voice"
api: "POST /v1/api/voices"
description: "Create a custom voice in your workspace from a voice embedding."
---

Creates the voice with Cartesia and adds it to your workspace. Get the `embedding` from [Clone Voice](/v1/api-reference/endpoints/voices/clone) first.

To use the voice, set it on a [call agent](/v1/api-reference/endpoints/agents/call/update) as `ttsModel: { "provider": "cartesia", "voiceId": "<id>" }`, using the `id` from the response.

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Request Body

<ParamField body="name" type="string" required>
Name for the custom voice.
</ParamField>

<ParamField body="embedding" type="array" required>
The `embedding` returned by Clone Voice, sent unchanged.
</ParamField>

<ParamField body="description" type="string">
Description of the custom voice.
</ParamField>

<ParamField body="language" type="string" default="en">
Language code for the voice (e.g., "en").
</ParamField>

## Response

`200` with the voice object Cartesia returns, passed through unchanged.

<ResponseField name="id" type="string">
The voice ID. Use it as `ttsModel.voiceId` (with provider `cartesia`) and to [delete the voice](/v1/api-reference/endpoints/voices/delete).
</ResponseField>

<ResponseField name="name" type="string">
Name of the custom voice.
</ResponseField>

<ResponseField name="description" type="string">
Description of the custom voice.
</ResponseField>

<ResponseField name="language" type="string">
Language code of the voice.
</ResponseField>

<ResponseField name="created_at" type="string">
Timestamp when the voice was created.
</ResponseField>

## Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "Workspace ID is required"}` | No `x-workspace-id` |
| `400` | `{"error": "Name and embedding are required"}` | `name` or `embedding` is missing |
| `500` | `{"error": "..."}` | Cartesia refused the request (for example a malformed embedding), or anything else went wrong |
