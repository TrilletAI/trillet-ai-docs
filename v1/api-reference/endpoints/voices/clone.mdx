---
title: "Clone Voice"
api: "POST /v1/api/voices/clone"
description: "Turn an audio clip into a voice embedding you can use to create a custom voice."
---

Cloning is the first of two steps. This endpoint sends your clip to Cartesia and returns its voice embedding. Nothing is saved to your workspace yet: pass the returned `embedding` to [Create Custom Voice](/v1/api-reference/endpoints/voices/create) to create the voice.

<Note>
Only the audio file is read. Form fields such as `name`, `description` or `language` are currently ignored, so this call never creates a voice by itself. Send those values to Create Custom Voice instead.
</Note>

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Request Body

The request body should be sent as `multipart/form-data`.

<ParamField body="file" type="file" required>
Audio clip to clone the voice from. One file, up to 50MB. The clip is sent to Cartesia with noise enhancement turned on.
</ParamField>

## Response

`200` with Cartesia's clone response, passed through unchanged. Its `embedding` is what Create Custom Voice needs.

<ResponseField name="embedding" type="array">
The voice embedding. Send it as-is to Create Custom Voice.
</ResponseField>

## Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "Audio file is required"}` | No file in the request |
| `500` | `{"error": "..."}` | Cartesia refused the clip, or anything else went wrong |

<RequestExample>
```bash
curl -X POST https://api.trillet.ai/v1/api/voices/clone \
  -H "x-api-key: YOUR_API_KEY" \
  -H "x-workspace-id: YOUR_WORKSPACE_ID" \
  -F "file=@sample.wav"
```
</RequestExample>

<ResponseExample>
```json
{
  "embedding": [0.0123, -0.0456, 0.0789]
}
```
</ResponseExample>
