---
title: "Create Workspace"
api: "POST /v1/api/workspaces"
description: "Create a new workspace with the authenticated user as the owner."
---

The new workspace is a **sub-workspace of your master workspace** (`parentWorkspaceId` is set to the master). It uses your master workspace's plan tier, and if the master is white-labelled (agency mode) it inherits the master's branding.

Creating workspaces is subject to your plan's workspace limit (see the errors below).

### Headers

<ParamField header="x-workspace-id" type="string" required>
  The `_id` of any workspace you're a member of. Required by the API-key auth check. It doesn't affect where the new workspace is created.
</ParamField>

### Request Body

<ParamField body="name" type="string" required>
  The name of the workspace (for example `"Marketing Team Workspace"`).
</ParamField>

<ParamField body="initials" type="string" required>
  Initials shown for the workspace (for example `"MT"`).
</ParamField>

Any other fields are ignored.

### Response

The new workspace object, including:

<ResponseField name="_id" type="string">
  The new workspace's ID.
</ResponseField>

<ResponseField name="name" type="string">
  The workspace name.
</ResponseField>

<ResponseField name="initials" type="string">
  The workspace initials.
</ResponseField>

<ResponseField name="parentWorkspaceId" type="string">
  Your master workspace's ID.
</ResponseField>

<ResponseField name="teamMembers" type="array">
  The workspace's team members, starting with you as the owner.
</ResponseField>

<ResponseField name="createdAt" type="string">
  When the workspace was created (ISO 8601).
</ResponseField>

<ResponseField name="updatedAt" type="string">
  When the workspace was last updated (ISO 8601).
</ResponseField>

### Studio plan: paying for an extra workspace

On a Studio plan, creating a workspace past the plan's included number returns `402`. For API-key requests, the response includes a Stripe Checkout link:

```json
{
  "error": "Your current plan is limited to <limit> workspaces. Please upgrade to create more.",
  "requiresPayment": true,
  "isStudioPlan": true,
  "sessionId": "cs_live_...",
  "sessionUrl": "https://checkout.stripe.com/c/pay/cs_live_...",
  "message": "Your Studio plan workspace limit has been reached. ..."
}
```

Send the user to `sessionUrl`. The workspace is created automatically, with the `name` and `initials` you sent, once payment succeeds. It is **not** created by this request.

### Errors

| Status | Body | When |
| --- | --- | --- |
| `402` | `{"error": "...", "requiresPayment": true, "isStudioPlan": true, ...}` | Studio plan over its included workspaces (see above) |
| `403` | `{"error": "Please subscribe to a plan to create workspaces", "subscriptionCanceled": true}` | Your subscription is cancelled |
| `423` | `{"error": "...", "code": "WORKSPACE_CHANGE_IN_PROGRESS"}` | Another workspace create or restore for your account is still running. Retry shortly |
| `500` | `{"error": "Workspace name was not defined"}` | `name` missing |
| `500` | `{"error": "..."}` | `initials` missing, your plan's workspace limit is reached (non-Studio plans and trials), or another server error |

<RequestExample>
```json
{
  "name": "Marketing Team Workspace",
  "initials": "MT"
}
```
</RequestExample>
