---
title: "Update Workspace Name"
api: "PUT /v1/api/workspaces/{workspaceId}"
description: "Rename a workspace, or change its display currency."
---

Your role needs the `workspace:edit` permission. For a client workspace under an agency or Studio master, you also need `agency_hub:edit` on the master workspace.

<Note>
Send **either** `name` **or** `displayCurrency`. If `displayCurrency` is present, only the currency is updated and `name` is ignored.
</Note>

### Path Parameters

<ParamField path="workspaceId" type="string" required>
  The `_id` of the workspace to update.
</ParamField>

### Headers

<ParamField header="x-workspace-id" type="string" required>
  A workspace where your role has `workspace:edit`. Permissions are checked against this header, so it's normally the same workspace as `workspaceId`.
</ParamField>

### Request Body

<ParamField body="name" type="string">
  The new name for the workspace. Leaving out both fields returns `200` with nothing changed.
</ParamField>

<ParamField body="displayCurrency" type="string">
  The currency code to display amounts in, for example `usd` or `aud`. Stored in lowercase.
</ParamField>

### Response

The full updated workspace object (the same shape as [Get Workspace by ID](/v1/api-reference/endpoints/workspace/get-workspace-by-id)), including:

<ResponseField name="_id" type="string">
  The workspace ID.
</ResponseField>

<ResponseField name="name" type="string">
  The workspace name.
</ResponseField>

<ResponseField name="initials" type="string">
  The workspace initials.
</ResponseField>

<ResponseField name="teamMembers" type="array">
  The workspace's team members.
</ResponseField>

<ResponseField name="createdAt" type="string">
  When the workspace was created (ISO 8601).
</ResponseField>

<ResponseField name="updatedAt" type="string">
  When the workspace was last updated (ISO 8601).
</ResponseField>

### Errors

| Status | Body | When |
| --- | --- | --- |
| `403` | `{"error": "Insufficient permissions", ...}` | Your role lacks `workspace:edit` |
| `403` | `{"error": "Insufficient permissions to update workspace"}` | Client workspace and you lack `agency_hub:edit` on the master |
| `404` | `{"error": "Workspace not found"}` | No workspace with that ID that you can see |
| `500` | `{"error": "..."}` | Unexpected server error |

```json

```
</RequestExample>
