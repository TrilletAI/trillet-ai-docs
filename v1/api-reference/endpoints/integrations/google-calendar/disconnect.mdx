---
title: "Disconnect Google Calendar"
api: "DELETE /v1/api/gcal/disconnect"
description: "Disconnect the Google Calendar integration from a call flow."
---

Removes the stored Google tokens from the call flow and turns the integration off. It also resets the calendar settings: the selected calendar, the free/busy and booking calendars, multi-calendar booking, and the slot duration (back to 30 minutes).

<Note>
If the call flow has an unpublished draft open in the editor, the change is saved to the draft only. Live calls keep the old setting until the draft is published.
</Note>

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API. The call flow must belong to this workspace (or one of its sub-workspaces).
</ParamField>

## Query Parameters

<ParamField query="pathwayId" type="string" required>
The `_id` of the call flow to disconnect Google Calendar from.
</ParamField>

## Response Fields

<ResponseField name="success" type="boolean">
`true` when the integration was disconnected.
</ResponseField>

## Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "pathwayId query parameter is required"}` | No `pathwayId` |
| `400` | `{"error": "Invalid pathwayId"}` | `pathwayId` isn't a valid ID |
| `403` | `{"error": "You do not have access to this workspace."}` | You aren't a member of the `x-workspace-id` workspace |
| `403` | `{"error": "Pathway does not belong to this workspace."}` | The flow belongs to another workspace |
| `404` | `{"error": "Pathway not found"}` | No call flow with that ID |
| `500` | `{"error": "..."}` | The disconnect failed |

}

</ResponseExample>
