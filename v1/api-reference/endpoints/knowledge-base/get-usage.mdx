---
title: "Get Knowledge Base Usage"
api: "GET /v1/api/knowledgebase/{id}/usage"
description: "See which call flows and message flows use a knowledge base."
---

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
The unique identifier of the knowledge base.
</ParamField>

## Response Fields

<ResponseField name="pathways" type="array">
Every call flow and message flow in the workspace that has this knowledge base attached. Call flows come first, then message flows; the items don't say which kind each one is. Empty if nothing uses it.

<ResponseField name="_id" type="string">
ID of the call flow or message flow.
</ResponseField>

<ResponseField name="name" type="string">
Name of the flow.
</ResponseField>

</ResponseField>

<ResponseExample>
```json
{
  "pathways": [
    {
      "_id": "a4a4a4a4a4a4a4a4a4a4a4a4",
      "name": "Customer Support Flow"
    },
    {
      "_id": "a5a5a5a5a5a5a5a5a5a5a5a5",
      "name": "Sales Inquiry Flow"
    }
  ]
}
```
</ResponseExample>
