---
title: "Create Knowledge Base"
api: "POST /v1/api/knowledgebase"
description: "Create a new knowledge base in your workspace."
---

Creates an empty knowledge base. Add content with [Upload File](/v1/api-reference/endpoints/knowledge-base/upload-file) or [Add Text](/v1/api-reference/endpoints/knowledge-base/add-text), then attach it to a call flow through the flow's `settings.knowledgeBases`.

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Request Body

<ParamField body="name" type="string" required>
Name of the knowledge base.
</ParamField>

<ParamField body="description" type="string">
Description of the knowledge base.
</ParamField>

<ParamField body="isSMB" type="boolean" default="false">
`true` creates a Basic knowledge base, meant for text set with Add Text. The agent reads that text in full instead of searching an index. A call flow can have at most one Basic knowledge base attached; attaching a second fails with `400` on the call flow update.
</ParamField>

## Response

`201` with the new knowledge base, in the same shape as [Get Knowledge Base](/v1/api-reference/endpoints/knowledge-base/get). `files` is empty.

## Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"message": "X-Workspace-ID header is required"}` | No `x-workspace-id` |
| `400` | `{"message": "Knowledge base name is required."}` | `name` is missing or empty |
| `500` | `{"message": "..."}` | Anything else |
