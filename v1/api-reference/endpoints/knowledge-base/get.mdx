---
title: "Get Knowledge Base"
api: "GET /v1/api/knowledgebase/{id}"
description: "Retrieve a specific knowledge base by its ID."
---

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
The unique identifier of the knowledge base.
</ParamField>

## Response

<ResponseField name="_id" type="string">
Unique identifier for the knowledge base.
</ResponseField>

<ResponseField name="name" type="string">
Name of the knowledge base.
</ResponseField>

<ResponseField name="description" type="string">
Description of the knowledge base, if one was given.
</ResponseField>

<ResponseField name="workspaceId" type="string">
Workspace ID associated with the knowledge base.
</ResponseField>

<ResponseField name="isSMB" type="boolean">
`true` for a Basic knowledge base (the agent reads its text in full rather than searching an index), `false` for a standard one.
</ResponseField>

<ResponseField name="files" type="array">
Uploaded files plus, if set, the text entry. At most 5 entries.

<Expandable title="properties">

<ResponseField name="_id" type="string">
ID of the entry.
</ResponseField>

<ResponseField name="filename" type="string">
File name, or the label of the text entry.
</ResponseField>

<ResponseField name="key" type="string">
Storage key of the file.
</ResponseField>

<ResponseField name="url" type="string">
Storage location of the file. Empty for the text entry.
</ResponseField>

<ResponseField name="mimetype" type="string">
MIME type. May be empty on older entries.
</ResponseField>

<ResponseField name="size" type="number">
Size in bytes (characters for the text entry). `0` on older entries.
</ResponseField>

<ResponseField name="isText" type="boolean">
`true` for the text entry set with [Add Text](/v1/api-reference/endpoints/knowledge-base/add-text).
</ResponseField>

<ResponseField name="uploadedAt" type="string">
When the entry was added.
</ResponseField>

</Expandable>
</ResponseField>

<ResponseField name="textContent" type="string">
The knowledge base's text, if any was set with Add Text.
</ResponseField>

<ResponseField name="usedInPathways" type="array">
Legacy field, usually empty. Use [Get Knowledge Base Usage](/v1/api-reference/endpoints/knowledge-base/get-usage) to see which flows use the knowledge base.
</ResponseField>

<ResponseField name="createdAt" type="string">
Timestamp when the knowledge base was created.
</ResponseField>

<ResponseField name="updatedAt" type="string">
Timestamp when the knowledge base was last updated.
</ResponseField>

## Errors

| Status | Body | When |
| --- | --- | --- |
| `404` | `{"message": "Knowledge base not found"}` | No knowledge base with this ID in the workspace |
| `500` | `{"message": "Failed to retrieve knowledge base"}` | Anything else, including a malformed ID |
