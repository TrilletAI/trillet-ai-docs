---
title: "Unassign Phone Number from Agent"
api: "POST /v1/api/agents/{agentId}/release/{phoneNumberId}"
description: "Unassign a phone number from an agent's call flow. This removes the assignment and automatically cleans up associated SIP trunking."
---

The number stays in your workspace, with no agent or call flow, until you [assign it](/v1/api-reference/endpoints/telephony/bind-call-to-phoneNumber) again. To give the number up entirely, use [Release Phone Number](/v1/api-reference/endpoints/phone-numbers/release).

Requires the `agent:edit` permission.

### Path Parameters

<ParamField path="agentId" type="string" required>
  The ID of the agent whose phone number will be released.
</ParamField>

<ParamField path="phoneNumberId" type="string" required>
  The `_id` of the phone number to unassign. It must currently be assigned to this agent.
</ParamField>

### Headers

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API. Required to scope the release operation.
</ParamField>

### Request Body

No request body is read. If you send `Content-Type: application/json`, send `{}` as the body.

### Response

`200` with the updated agent, in the same shape as [Get Call Agent](/v1/api-reference/endpoints/agents/call/get) except that `phoneNumberIds` holds IDs, not objects.

### Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "Workspace ID is required"}` | No `x-workspace-id` |
| `403` | `{"error": "Insufficient permissions"}` | Your role doesn't have `agent:edit` |
| `500` | `{"error": "Agent not found or does not belong to the workspace"}` | No agent with this ID in the workspace. This is currently a `500`, not a `404` |
| `500` | `{"error": "Phone number not associated with this agent"}` | The number isn't assigned to this agent |
| `500` | `{"error": "..."}` | Anything else |
