---
title: "Assign Phone Number to Agent"
api: "POST /v1/api/agents/{agentId}/bind/{phoneNumberId}"
description: "Assign a phone number to an agent's call flow, set recording, office hours and metadata, and configure the SIP trunks."
---

This is how a number gets attached to an agent: [Create Call Agent](/v1/api-reference/endpoints/agents/call/create) ignores `phoneNumberIds`. The agent must already belong to a live call flow. If the number was on another agent, it is moved to this one.

Requires the `agent:edit` permission.

### Path Parameters

<ParamField path="agentId" type="string" required>
  The ID of the agent whose call flow will be bound to the phone number.
</ParamField>

<ParamField path="phoneNumberId" type="string" required>
  The `_id` of the phone number to bind, from [List Phone Numbers](/v1/api-reference/endpoints/phone-numbers/list). It must belong to this workspace.
</ParamField>

### Headers

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API. Required to scope the binding operation.
</ParamField>

### Request Body

A JSON body is required. Send `{}` if you don't want to set anything.

<ParamField body="recordCalls" type="boolean" optional>
  Whether calls on this number are recorded. Left out, the current setting is kept.
</ParamField>

<ParamField body="recordingPublic" type="boolean" optional>
  Whether recordings are publicly accessible. Left out, the current setting is kept.
</ParamField>

<ParamField body="officeHours" type="object" optional>
  Office hours for the number, in the same shape as [Update Phone Number Configuration](/v1/api-reference/endpoints/phone-numbers/update-config): `enabled`, `start` and `end` (`HH:MM`), `timezone` (IANA), `allowedDays` (`Mon` to `Sun`) and `blockedDates`. Left out, the stored office hours are kept.
</ParamField>

<ParamField body="metadataTags" type="object" optional>
  Key/value tags to store with the number, as an object of strings, for example `{ "department": "sales", "priority": "high" }`.

  <Warning>
  The tags you send replace all existing tags, and **leaving `metadataTags` out clears them**. Send the current tags again to keep them.
  </Warning>
</ParamField>

<ParamField body="label" type="string" optional>
  A label for the number. Left out, the current label is kept.
</ParamField>

<ParamField body="transferCallerIdMode" type="string" optional>
  Caller ID shown on transferred calls: `from-transferee` (default, the original caller's number) or `from-transferor` (your Trillet number).
</ParamField>

<ParamField body="secretBindings" type="object" optional>
  Map of alias to workspace secret name, for example `{ "crm_key": "acme-crm" }`. Every name must be an existing secret in this workspace. Replaces all existing bindings; left out, they are kept.
</ParamField>

### Response Fields

<ResponseField name="agent" type="object">
  The updated agent object, including its bound phone number IDs.
</ResponseField>

<ResponseField name="phoneNumber" type="object">
  The updated phone number object after binding and SIP trunk configuration.
</ResponseField>

<ResponseField name="pathwayId" type="string">
  The ID of the call flow associated with this assignment.
</ResponseField>

<ResponseField name="direction" type="string">
  The direction of the call flow (`outbound` or `bidirectional`).
</ResponseField>

### Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "Workspace ID is required"}` | No `x-workspace-id` |
| `400` | `{"error": "..."}` | `secretBindings` is malformed or names a secret that doesn't exist |
| `403` | `{"error": "Insufficient permissions"}` | Your role doesn't have `agent:edit` |
| `404` | `{"message", "code": "AGENT_NOT_FOUND", "error"}` | No agent with this ID in the workspace |
| `404` | `{"message", "code": "PHONE_NUMBER_NOT_FOUND", "error"}` | No number with this ID in the workspace |
| `409` | `{"message", "code": "CALL_FLOW_ARCHIVED", "error"}` | Every call flow of the agent is archived or inactive. Restore or turn one on first |
| `409` | `{"message", "code": "AGENT_HAS_NO_CALL_FLOW", "error"}` | The agent isn't used by any call flow |
| `500` | `{"error": "..."}` | Anything else, including a request with no body |

When a request is refused, nothing is changed.
