---
title: "Switch to a Schedule"
api: "POST /v1/api/call-flows/{id}/office-hours/schedules/{scheduleId}/activate"
description: "Replace the weekly hours with a saved schedule in one call."
---

Copies the saved week into the flow's live weekly hours. This is the call to drive from your own scheduler or automation when a department changes its pattern.

Date exceptions are stored separately and are **not** cleared by switching schedules.

## Headers

<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
The unique ID of the call flow.
</ParamField>

<ParamField path="scheduleId" type="string" required>
The schedule's id **or its name**, so you can activate by name without storing ids.
</ParamField>

<RequestExample>
```bash By name
curl -X POST 'https://api.trillet.ai/v1/api/call-flows/{flowId}/office-hours/schedules/Storm/activate' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'x-workspace-id: YOUR_WORKSPACE_ID'
```
</RequestExample>
