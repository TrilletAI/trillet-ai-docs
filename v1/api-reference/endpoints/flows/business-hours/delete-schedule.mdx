---
title: "Delete a Schedule"
api: "DELETE /v1/api/call-flows/{id}/office-hours/schedules/{scheduleId}"
description: "Remove a saved schedule."
---

Removes the saved week. The flow's current weekly hours are left as they are, even if this schedule was the one most recently activated.

## Headers

<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
The unique ID of the call flow.
</ParamField>

<ParamField path="scheduleId" type="string" required>
The schedule's id or its name.
</ParamField>

<RequestExample>
```bash cURL
curl -X DELETE 'https://api.trillet.ai/v1/api/call-flows/{flowId}/office-hours/schedules/Storm' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'x-workspace-id: YOUR_WORKSPACE_ID'
```
</RequestExample>
