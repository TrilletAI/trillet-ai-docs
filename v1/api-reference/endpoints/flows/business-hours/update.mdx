---
title: "Update Business Hours"
api: "PUT /v1/api/call-flows/{id}/office-hours"
description: "Change the weekly hours, the timezone, or whether the hours are in use."
---

Send any combination of the three fields. Anything you leave out is untouched, so a timezone change does not have to resend the week.

## Headers

<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
The unique ID of the call flow.
</ParamField>

## Request Body

<ParamField body="perDay" type="object">
The weekly hours. Keys are `Monday` through `Sunday`; days you omit fall back to closed.
<Expandable title="perDay[day]">
  <ParamField body="enabled" type="boolean" required>
    Whether the business is open on this day.
  </ParamField>
  <ParamField body="start" type="string">
    Opening time as 24-hour `HH:MM`.
  </ParamField>
  <ParamField body="end" type="string">
    Closing time as 24-hour `HH:MM`. Must be later than `start`; hours running past midnight are not supported.
  </ParamField>
</Expandable>
</ParamField>

<ParamField body="timezone" type="string">
IANA timezone the hours are read in, for example `America/New_York`.
</ParamField>

<ParamField body="holdOutboundCalls" type="boolean">
Whether these hours are in use. While `false` the agent does not read them and outbound calls are not held.
</ParamField>

<ParamField body="version" type="string">
The `version` from your last read. The write is refused with `409` `HOURS_CHANGED` if the hours changed since. Omit it to merge and retry instead.
</ParamField>

<Note>
At least one of `perDay`, `timezone` or `holdOutboundCalls` must be present, or the request is rejected with `400`.
</Note>

<RequestExample>
```bash cURL
curl -X PUT 'https://api.trillet.ai/v1/api/call-flows/{flowId}/office-hours' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'x-workspace-id: YOUR_WORKSPACE_ID' \
  -H 'Content-Type: application/json' \
  -d '{
    "timezone": "America/New_York",
    "perDay": {
      "Monday":    { "enabled": true,  "start": "08:00", "end": "20:00" },
      "Tuesday":   { "enabled": true,  "start": "08:00", "end": "20:00" },
      "Wednesday": { "enabled": true,  "start": "08:00", "end": "20:00" },
      "Thursday":  { "enabled": true,  "start": "08:00", "end": "20:00" },
      "Friday":    { "enabled": true,  "start": "08:00", "end": "18:00" },
      "Saturday":  { "enabled": true,  "start": "08:00", "end": "22:00" },
      "Sunday":    { "enabled": false, "start": "09:00", "end": "17:00" }
    }
  }'
```

```bash Just the cutoff time
curl -X PUT 'https://api.trillet.ai/v1/api/call-flows/{flowId}/office-hours' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'x-workspace-id: YOUR_WORKSPACE_ID' \
  -H 'Content-Type: application/json' \
  -d '{"perDay": {"Friday": {"enabled": true, "start": "08:00", "end": "16:00"}}}'
```
</RequestExample>
