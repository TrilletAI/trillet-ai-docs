title: "Delete Call Flow Knowledge File"

description: "Delete a knowledge file uploaded for call flows."
---

### Headers

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

### Path Parameters

<ParamField path="fileKey" type="string" required>
  File key returned when the knowledge file was uploaded. The path does not
  include a call flow id.
</ParamField>
