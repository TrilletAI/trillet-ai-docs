---
title: "Delete Call Flow Knowledge Base File"
api: "DELETE /v1/api/call-flows/knowledge-base/{fileKey}"
description: "Delete a call-flow knowledge base file by its storage key."
---

Delete a knowledge base file. The path does not include a call flow id.

### Headers

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

### Path Parameters

<ParamField path="fileKey" type="string" required>
  Storage key of the knowledge base file to delete.
</ParamField>
