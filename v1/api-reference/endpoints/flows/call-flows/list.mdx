---
title: "List Call Flows"
api: "GET /v1/api/call-flows"
description: "Retrieve every call flow in the workspace, including archived ones."
---

### Headers  

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

The response is a plain array with one full call flow document per item, the same document [Get Call Flow](/v1/api-reference/endpoints/flows/call-flows/get) returns (settings, prompt versions and so on). There is no pagination or filtering.

<Note>
  Archived call flows are included. An archived flow has a non-null `archivedAt`; filter on it if you only want flows that can take calls.
</Note>

### Response Fields

<ResponseField name="_id" type="string">
  The unique identifier for the call flow.
</ResponseField>

<ResponseField name="workspaceId" type="string">
  The identifier of the workspace where the call flow is configured.
</ResponseField>

<ResponseField name="name" type="string">
  The name assigned to the call flow.
</ResponseField>

<ResponseField name="direction" type="string">
  `outbound` or `bidirectional` (answers inbound calls and can place outbound ones).
</ResponseField>

<ResponseField name="agent" type="object">
  The agent the flow uses, as a full agent object (`_id`, `name`, `ttsModel`, `llmModel`, `sttProvider`, `phoneNumberIds` and so on), with its `phoneNumberIds` populated as phone number objects. Use `agent._id` for the agent's ID. It is `null` if the flow has no agent.
</ResponseField>

<ResponseField name="folderId" type="object">
  The folder the flow is in, as `{ _id, name, icon, color }`, or `null`.
</ResponseField>

<ResponseField name="isActive" type="boolean">
  Whether the call flow is active.
</ResponseField>

<ResponseField name="archivedAt" type="string">
  When the flow was archived, or `null` if it is not archived. Archived flows are read-only and do not take calls.
</ResponseField>

<ResponseField name="promptType" type="string">
  `simple` (one prompt drives the call), `nodes` (a node-based flow) or `flow` (legacy).
</ResponseField>

<ResponseField name="settings" type="object">
  The flow's settings. See [Update Call Flow](/v1/api-reference/endpoints/flows/call-flows/update).
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the call flow was created.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp when the call flow was last updated.
</ResponseField>
