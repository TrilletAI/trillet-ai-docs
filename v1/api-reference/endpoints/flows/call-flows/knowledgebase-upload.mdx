---
title: "Upload Call Flow Knowledge File"
api: "POST /v1/api/call-flows/knowledge-base/upload"
description: "Upload a knowledge file for call flows."
---

### Headers

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

### Request Body

<ParamField body="file" type="file" required>
  The knowledge file to upload. Accepted formats are PDF (.pdf), plain text
  (.txt), Word (.docx), and Markdown (.md).
  <Note>
    One file per request. The path does not include a call flow id.
  </Note>
</ParamField>

The response includes the file key. Pass that key to [Delete Call Flow Knowledge File](/v1/api-reference/endpoints/flows/call-flows/knowledgebase-delete).
