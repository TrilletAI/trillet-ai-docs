---
title: "Get Call History Metrics"
api: "GET /v2/api/call-history/metrics"
description: "Retrieve aggregated metrics and analytics for call history records in your workspace."
---

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Query Parameters

The filters behave the same as on [List Call Histories](/v1/api-reference/endpoints/calls/call-history/list).

<ParamField query="agentId" type="string">
Filter by agent ID, or by agent name.
</ParamField>

<ParamField query="status" type="string">
Filter by call status: `completed`, `pending`, `failed` or `blocked`.
</ParamField>

<ParamField query="direction" type="string">
Filter by call direction: `inbound`, `outbound` or `web`.
</ParamField>

<ParamField query="pathwayId" type="string">
Filter by call flow ID.
</ParamField>

<ParamField query="batchId" type="string">
Filter by batch call ID.
</ParamField>

<ParamField query="callIds" type="string">
JSON-stringified array of call IDs.
</ParamField>

<ParamField query="dateRange" type="string">
JSON string with `startDate` and `endDate` ISO 8601 timestamps, applied to the call start time in UTC. Example: `{"startDate":"2024-01-01T00:00:00Z","endDate":"2024-01-31T23:59:59Z"}`. An invalid value returns `400`.
</ParamField>

<ParamField query="callType" type="string">
Filter by call type: `sip` or `web`.
</ParamField>

<ParamField query="search" type="string">
Free-text search, same as on List Call Histories. At most 200 characters.
</ParamField>

<ParamField query="fromPhone" type="string">
Partial match on the caller number (digits only).
</ParamField>

<ParamField query="toPhone" type="string">
Partial match on the destination number (digits only).
</ParamField>

<ParamField query="postAnalysis" type="string">
JSON-stringified array of post-call analysis filter objects, same as on List Call Histories. A single object is ignored.
</ParamField>

## Response Fields

<ResponseField name="totalCalls" type="number">
Number of calls matching the filters.
</ResponseField>

<ResponseField name="avgDuration" type="string">
Average call duration formatted as `m:ss`. `"0:00"` when there are no calls.
</ResponseField>

<ResponseField name="completionRate" type="string">
Share of matching calls with status `completed`, as a percentage string rounded to one decimal place. `"0%"` when there are no calls.
</ResponseField>

<ResponseExample>
```json
{
  "totalCalls": 70,
  "avgDuration": "0:42",
  "completionRate": "98.6%"
}
```
</ResponseExample>
