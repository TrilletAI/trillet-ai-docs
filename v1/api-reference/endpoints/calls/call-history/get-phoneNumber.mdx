---
title: "Get Phone Numbers"
api: "GET /v1/api/twilio/user-phone-numbers"
description: "Retrieve every phone number in the workspace."
---

This is the same endpoint as [List Phone Numbers](/v1/api-reference/endpoints/phone-numbers/list). It returns all phone numbers in the workspace, not only those added by the calling user. The caller's role needs phone number view permission (otherwise `403 {"error": "Insufficient permissions"}`).

### Headers

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

### Response

The response is a JSON array of phone number objects (not wrapped in an object). An empty workspace returns `[]`. Commonly used fields:

<ResponseField name="_id" type="string">
  Phone number record ID.
</ResponseField>

<ResponseField name="phoneNumber" type="string">
  The number in E.164 format.
</ResponseField>

<ResponseField name="sid" type="string">
  Provider identifier for the number.
</ResponseField>

<ResponseField name="provider" type="string">
  `twilio`, `sip`, `telnyx`, `commschannel` or `whatsapp`.
</ResponseField>

<ResponseField name="isExternal" type="boolean">
  `true` for numbers imported from your own carrier account.
</ResponseField>

<ResponseField name="country" type="string">
  Country code of the number.
</ResponseField>

<ResponseField name="status" type="string">
  `ready`, `active`, `released`, `reserved` or `error`.
</ResponseField>

<ResponseField name="flowType" type="string">
  What the number is bound to: `call`, `message`, `both` or `undefined`.
</ResponseField>

<ResponseField name="agentId" type="object">
  The bound agent, returned as the full agent object, or `null`.
</ResponseField>

<ResponseField name="pathwayId" type="object">
  The bound call flow, returned as the full call flow object, or `null`.
</ResponseField>

<ResponseField name="messagePathwayId" type="object">
  The bound message flow object, or `null`.
</ResponseField>

<ResponseField name="omniFlowAgentId" type="object">
  The bound omni-channel agent object, or `null`.
</ResponseField>

<ResponseField name="recordingEnabled" type="boolean">
  Whether call recording is enabled on the number.
</ResponseField>

<ResponseField name="monthlyPrice" type="number">
  Monthly price of the number.
</ResponseField>

<ResponseField name="scheduledReleaseAt" type="string">
  ISO date when a cancelled number will be released, or `null`.
</ResponseField>

<ResponseField name="cancelAtPeriodEnd" type="boolean">
  Whether the number's subscription is set to cancel at the end of the period.
</ResponseField>

<ResponseField name="subscriptionStatus" type="string">
  Status of the number's subscription, or `null`.
</ResponseField>

<ResponseField name="subscriptionExpiresAt" type="string">
  When the subscription expires, or `null`.
</ResponseField>

<ResponseField name="createdAt" type="string">
  Creation timestamp.
</ResponseField>
