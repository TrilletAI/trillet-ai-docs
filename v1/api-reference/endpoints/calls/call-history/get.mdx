---
title: "Get a Specific Call History"
api: "GET /v2/api/call-history/{callHistoryId}"
description: "Retrieve detailed information about a specific call history entry."
---

### Headers  

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

### Path Parameters

<ParamField path="callHistoryId" type="string" required>
  The call history record ID (the `_id` from [List Call Histories](/v1/api-reference/endpoints/calls/call-history/list)).
</ParamField>

### Response Fields

The record has the same shape as one item of `data` in [List Call Histories](/v1/api-reference/endpoints/calls/call-history/list), with these differences: the transcript is always included, and `pathwayName`, `telephonyCost`, `warmTransferCharge`, `warmTransferMinutes` and `mode` are not returned.

<ResponseField name="_id" type="string">
  The call history record ID.
</ResponseField>

<ResponseField name="timestamp" type="number">
  Call start time as Unix seconds.
</ResponseField>

<ResponseField name="callId" type="string">
  Call identifier.
</ResponseField>

<ResponseField name="roomName" type="string">
  Room name of the call. Web calls start with `web-`.
</ResponseField>

<ResponseField name="direction" type="string">
  `inbound`, `outbound` or `web`.
</ResponseField>

<ResponseField name="fromPhoneNumber" type="string">
  Caller number, or `"N/A"`.
</ResponseField>

<ResponseField name="toPhoneNumber" type="string">
  Destination number, or `"N/A"`.
</ResponseField>

<ResponseField name="status" type="string">
  `completed`, `pending`, `failed` or `blocked`.
</ResponseField>

<ResponseField name="duration" type="number">
  Call length in whole seconds. Omitted when zero or unknown.
</ResponseField>

<ResponseField name="agent" type="string">
  Agent name, or `"N/A"`.
</ResponseField>

<ResponseField name="callFlowName" type="string">
  Call flow name, or `"N/A"`.
</ResponseField>

<ResponseField name="cost" type="number">
  Amount charged for the call. `0` when not charged.
</ResponseField>

<ResponseField name="recordingUrl" type="string">
  Authenticated recording URL, or `null`.
</ResponseField>

<ResponseField name="summary" type="string">
  Call summary, or `null`.
</ResponseField>

<ResponseField name="analyzedData" type="object">
  Post-call analysis results. Keys depend on the call flow's post-call analysis settings.
</ResponseField>

<ResponseField name="transcript" type="array">
  Transcript entries.
</ResponseField>

<ResponseField name="functionCalls" type="array">
  Tool calls made during the call.
</ResponseField>

<ResponseField name="callEndedBy" type="string">
  Who ended the call, or `"Unknown"`. Phone calls only.
</ResponseField>

<ResponseField name="callEndReason" type="string">
  Why the call ended, or `"Unknown"`. Phone calls only.
</ResponseField>

See [List Call Histories](/v1/api-reference/endpoints/calls/call-history/list) for the remaining fields (`charged_duration`, `error`, `hasTelephonyCost`, `publicRecordingUrl`, `batchId`, `pendingReason`, `variables`, `dynamic_variables`, `llm`/`stt`/`tts`, `bookingOutcome` and others).

### Errors

<Note>
A record that does not exist, or belongs to another workspace, currently returns `500` rather than `404`. A malformed ID also returns `500`.
</Note>

| Status | Body | When |
|---|---|---|
| `500` | `{"error": "Call history record not found"}` | No record with that ID in this workspace |
| `500` | `{"error": "Cast to ObjectId failed ..."}` | `callHistoryId` is not a valid ID |
