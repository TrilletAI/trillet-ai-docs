---
title: "Export Call History CSV"
api: "POST /v2/api/call-history/export-csv"
description: "Export call history records as a CSV file with optional transcript and post-analysis data."
---

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Request Body

Send a JSON body, even if it is only `{}`. Filters behave the same as on [List Call Histories](/v1/api-reference/endpoints/calls/call-history/list), except that `callIds`, `dateRange` and `postAnalysis` are sent as JSON values, not strings.

<ParamField body="includeTranscripts" type="boolean" default="false">
Adds a `Transcript` column.
</ParamField>

<ParamField body="includePostAnalysis" type="boolean" default="false">
Adds one `analyzed_<key>` column per post-call analysis field.
</ParamField>

<ParamField body="includeDynamicVariables" type="boolean" default="false">
Adds one `dynamic_<key>` column per dynamic variable.
</ParamField>

<ParamField body="includeResponseVariables" type="boolean" default="false">
Adds one `response_<key>` column per response variable.
</ParamField>

<ParamField body="limit" type="integer">
Maximum number of records to export, newest first. Ignored unless it is a positive integer; without it every matching record is exported.
</ParamField>

<ParamField body="batchId" type="string">
Filter by batch call ID.
</ParamField>

<ParamField body="agentId" type="string">
Filter by agent ID, or by agent name.
</ParamField>

<ParamField body="pathwayId" type="string">
Filter by call flow ID.
</ParamField>

<ParamField body="status" type="string">
Filter by call status: `completed`, `pending`, `failed` or `blocked`.
</ParamField>

<ParamField body="direction" type="string">
Filter by call direction: `inbound`, `outbound` or `web`.
</ParamField>

<ParamField body="callType" type="string">
Filter by call type: `sip` or `web`.
</ParamField>

<ParamField body="callIds" type="array">
Export only these call IDs.
</ParamField>

<ParamField body="search" type="string">
Free-text search. At most 200 characters.
</ParamField>

<ParamField body="fromPhone" type="string">
Partial match on the caller number (digits only). At most 200 characters.
</ParamField>

<ParamField body="toPhone" type="string">
Partial match on the destination number (digits only). At most 200 characters.
</ParamField>

<ParamField body="isCallFromSmartCallback" type="boolean">
Filter to calls that were (or were not) placed by a smart callback.
</ParamField>

<ParamField body="postAnalysis" type="array">
Post-call analysis filters, same format as on List Call Histories.
</ParamField>

<ParamField body="dateRange" type="object">
Filter on call start time. Send either `startDate` and `endDate`, or `start` and `end`.

<Expandable title="properties">

<ParamField body="startDate" type="string">
Start date, ISO 8601.
</ParamField>

<ParamField body="endDate" type="string">
End date, ISO 8601.
</ParamField>

<ParamField body="start" type="number">
Start time as Unix seconds (used when `startDate`/`endDate` are not sent).
</ParamField>

<ParamField body="end" type="number">
End time as Unix seconds.
</ParamField>

</Expandable>
</ParamField>

## Response

The response is streamed as a CSV file with `Content-Type: text/csv; charset=utf-8` and `Content-Disposition: attachment`. The filename is `call_history.csv`, or `call_history_with_transcripts.csv` when `includeTranscripts` is true.

Columns, in order: Record ID, Call ID, Room Name, Agent Name, Call Flow Name, Start Time (UTC), End Time (UTC), Duration (s), Direction, From Phone Number, To Phone Number, Status, Twilio Call SID, Batch ID, Smart Callback, Recording Link, Analyzed Data (JSON), Cost, Has Telephony Cost, Summary, With AI Duration (s), Transferring Duration (s), With Transferee Duration (s), Agent Segments (JSON). Then `Transcript` and the `analyzed_`, `dynamic_` and `response_` columns when requested. The variable columns are discovered from the 50 most recent matching calls.

<Note>
`Cost` and `Has Telephony Cost` show `N/A` unless the caller's role has the `billing:view` permission.
</Note>

## Errors

| Status | Body | When |
|---|---|---|
| `400` | `{"error": "<field> must be ..."}` | `search`, `fromPhone` or `toPhone` is not a string, is over 200 characters, or (phone filters) has no digits |
| `500` | `{"error": "<message>"}` | Any other failure before streaming starts |
