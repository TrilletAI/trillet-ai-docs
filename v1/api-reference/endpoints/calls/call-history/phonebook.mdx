---
title: "Get Call Phonebook"
api: "GET /v2/api/call-history/phonebook"
description: "List recent destination numbers from call history."
---

Returns the distinct destination numbers from the workspace's 100 most recent phone calls (web calls are excluded). Only valid E.164 numbers are kept.

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Response

The response is a JSON array (not wrapped in an object). Each item has:

<ResponseField name="toPhoneNumber" type="string">
The phone number in E.164 format.
</ResponseField>

<ResponseExample>
```json
[
  { "toPhoneNumber": "+14155551234" },
  { "toPhoneNumber": "+14155555678" },
  { "toPhoneNumber": "+14155559012" }
]
```
</ResponseExample>
