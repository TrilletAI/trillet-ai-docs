---
title: "Get Daily Call Metrics"
api: "GET /v2/api/call-history/metrics/daily"
description: "Retrieve per-day call history metrics for the workspace."
---

Returns call history aggregates as a per-day series. Aggregate totals for the same window are on [Get Call History Metrics](/v1/api-reference/endpoints/calls/call-history/metrics).

## Headers

<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>
