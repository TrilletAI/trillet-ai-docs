---
title: "Get Batch Progress"
api: "GET /v1/api/batch-calls/{batchId}/status"
description: "Get the job counters and percent complete for a batch call operation"
---

### Headers
<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

### Path Parameters

<ParamField path="batchId" type="string" required>
  The 10-character batch ID returned by [Start Batch Calls](/v1/api-reference/endpoints/calls/batch/start).
</ParamField>

### Response

<ResponseField name="batchId" type="string">
  The batch ID.
</ResponseField>

<ResponseField name="total" type="number">
  Total jobs in the batch
</ResponseField>

<ResponseField name="completed" type="number">
  Dial jobs that finished
</ResponseField>

<ResponseField name="failed" type="number">
  Dial jobs that failed
</ResponseField>

<ResponseField name="waiting" type="number">
  Jobs waiting in the queue
</ResponseField>

<ResponseField name="active" type="number">
  Jobs currently being placed
</ResponseField>

<ResponseField name="progress" type="number">
  Percent of jobs completed, rounded to a whole number (0-100). Failed jobs are not counted as completed.
</ResponseField>

<ResponseField name="lastUpdated" type="number">
  Time these counters were read, in Unix milliseconds.
</ResponseField>

### Example Usage

```bash
curl -X GET "https://api.trillet.ai/v1/api/batch-calls/k3j9x0a1bq/status" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "x-workspace-id: YOUR_WORKSPACE_ID"
```

### Example Response

```json
{
  "batchId": "k3j9x0a1bq",
  "total": 150,
  "completed": 95,
  "failed": 5,
  "waiting": 45,
  "active": 5,
  "progress": 63,
  "lastUpdated": 1793284800000
}
```

### Error Responses

<ResponseField name="error" type="string">
  Error message describing what went wrong
</ResponseField>

**Common Error Codes:**
- `404` - `Batch not found`: the batch doesn't exist or belongs to another workspace
- `500` - Server error retrieving batch progress

<Note>
  Counters are kept for **7 days**. After that, or before a scheduled batch starts, every counter reads `0`. Use [Get Batch Status](/v1/api-reference/endpoints/calls/batch/get-status) for the batch's overall status.
</Note>
