---
title: "Get Individual Call Status"
api: "GET /v1/api/batch-calls/{batchId}/calls/{jobId}"
description: "Get the status of an individual call within a batch operation"
---

### Headers
<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

### Path Parameters

<ParamField path="batchId" type="string" required>
  The 10-character batch ID.
</ParamField>

<ParamField path="jobId" type="string" required>
  The job's numeric ID, from the `id` field of [List Batch Calls](/v1/api-reference/endpoints/calls/batch/list-calls).
</ParamField>

<Note>
  A status exists only once the job has started. A job that is still waiting in the queue returns `404 Call not found`. Statuses are kept for **7 days**. This endpoint reports the dial job, not the conversation: for the outcome, transcript and analysis use [Call History](/v1/api-reference/endpoints/calls/call-history/list) filtered by `batchId`.
</Note>

### Response

<ResponseField name="jobId" type="string | number">
  The numeric job ID.
</ResponseField>

<ResponseField name="batchId" type="string">
  The batch the job belongs to.
</ResponseField>

<ResponseField name="status" type="string">
  - `active` - The call is being placed
  - `completed` - The dial job finished. This doesn't mean the conversation succeeded.
  - `failed` - The dial job failed; see `error`
  - `cancelled` - The job was cancelled with Cancel Batch Job or Cancel Batch Contact
</ResponseField>

<ResponseField name="phoneNumber" type="string">
  The number that was called.
</ResponseField>

<ResponseField name="contact" type="string | null">
  The row's `contact` or `name` column, if present. Other columns (such as the template's `contact_name`) are not copied here.
</ResponseField>

<ResponseField name="business" type="string | null">
  The row's `business` or `company` column, if present.
</ResponseField>

<ResponseField name="startTime" type="number">
  `active` jobs only. When the job started, in Unix milliseconds.
</ResponseField>

<ResponseField name="endTime" type="number">
  `completed`, `failed` and `cancelled` jobs. When the job ended, in Unix milliseconds.
</ResponseField>

<ResponseField name="callDuration" type="number">
  `completed` jobs only. Call duration from Call History, or `0` if it wasn't found.
</ResponseField>

<ResponseField name="roomName" type="string">
  `completed` jobs only. The call's room name, when known.
</ResponseField>

<ResponseField name="error" type="string">
  `failed` jobs only. Why the job failed.
</ResponseField>

### Example Usage

```bash
curl -X GET "https://api.trillet.ai/v1/api/batch-calls/k3j9x0a1bq/calls/4821" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "x-workspace-id: YOUR_WORKSPACE_ID"
```

### Error Responses

<ResponseField name="error" type="string">
  Error message describing what went wrong
</ResponseField>

**Common Error Codes:**
- `404` - `Call not found`: the job hasn't started yet, doesn't exist, isn't part of this batch, or its 7-day status has expired. `Batch not found` when the batch doesn't exist or belongs to another workspace.
- `500` - Server error retrieving call status
