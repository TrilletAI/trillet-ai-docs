---
title: "Validate Batch CSV"
api: "POST /v1/api/batch-calls/validate"
description: "Check a batch-call CSV before starting the batch."
---

### Headers

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

### Request Body

This endpoint accepts `multipart/form-data`.

<ParamField body="file" type="file" required>
  CSV file to validate. Maximum file size: 20MB. Use the columns from [Download Batch CSV Template](/v1/api-reference/endpoints/calls/batch/template).
</ParamField>

### Example

```bash
curl -X POST "https://api.trillet.ai/v1/api/batch-calls/validate" \
  -H "x-api-key: YOUR_API_KEY" \
  -H "x-workspace-id: YOUR_WORKSPACE_ID" \
  -F "file=@contacts.csv"
```
