---
title: 'Create Call Agent'
api: 'POST /v1/api/agents'
description: 'Create a new agent for a workspace.'
---

An agent holds the voice, speech-to-text and language model a call flow speaks with. Create the agent first, then pass its `_id` as `agent` when you [create a call flow](/v1/api-reference/endpoints/flows/call-flows/create).

<Note>
Phone numbers are not attached here. Once the agent belongs to a call flow, attach a number with [Assign Phone Number to Agent](/v1/api-reference/endpoints/telephony/bind-call-to-phoneNumber).
</Note>

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Request Body

<ParamField body="name" type="string" required>
Name of the agent being created.
</ParamField>

<ParamField body="ttsModel" type="object" required>
Text-to-Speech (TTS) configuration for the agent. `provider` and `voiceId` are both required.

<Expandable title="properties">

<ParamField body="provider" type="string" required>
TTS provider. One of `rime`, `openai`, `openai-live`, `elevenlabs`, `11labs_byo`, `cartesia`, `cartesia_byo`, `google`, `gemini-3.8-flash`, `gemini-3.8-flash-lite`, `azure`, `hume`, `xai`, `grok`, `deepgram`, `fish`. A value outside this list fails with `500`.

Custom voices you create with the [Voices API](/v1/api-reference/endpoints/voices/create) use `cartesia`.
</ParamField>

<ParamField body="voiceId" type="string" required>
The voice to speak with. Take it from the `voiceId` field of [Search Voices](/v1/api-reference/endpoints/voices/search) rather than hardcoding one, because the catalog changes. Trillet Voices (provider `rime`) look like `mistv3_wildflower`, `mistv3_brook` or `mistv3_violet`.
</ParamField>

<ParamField body="name" type="string">
Display name of the voice, for example `Wildflower`.
</ParamField>

<ParamField body="rimeModel" type="string">
Rime model for a `rime` voice, for example `mistv3`. Search Voices returns it with each Rime voice.
</ParamField>

<ParamField body="elevenLabsModel" type="string">
ElevenLabs model. One of `eleven_turbo_v2`, `eleven_flash_v2_5`, `eleven_turbo_v2_5`, `eleven_multilingual_v2`, `eleven_v4`, `eleven_v4_turbo`.
</ParamField>

<ParamField body="language" type="string" default="en">
Language code (e.g., en, fr).
</ParamField>

<ParamField body="elevenLabsApiKey" type="string">
Your ElevenLabs API key, used only when provider is `11labs_byo`. It is encrypted before it is stored.
</ParamField>

<ParamField body="elevenLabsApiKeySecret" type="string">
Name of a workspace secret that holds your ElevenLabs key, as an alternative to `elevenLabsApiKey`.
</ParamField>

<ParamField body="cartesiaApiKey" type="string">
Your Cartesia API key, used only when provider is `cartesia_byo`. It is encrypted before it is stored.
</ParamField>

<ParamField body="cartesiaApiKeySecret" type="string">
Name of a workspace secret that holds your Cartesia key, as an alternative to `cartesiaApiKey`.
</ParamField>

</Expandable>
</ParamField>

<ParamField body="fallbackTtsModel" type="object">
Optional second voice, used if the primary TTS provider fails during a call. Same fields as `ttsModel`.
</ParamField>

<ParamField body="sttProvider" type="object">
Speech-to-text provider, as `{ "id": "...", "name": "...", "description": "..." }`. `id` is one of `deepgram-nova-2`, `deepgram-nova-3`, `deepgram-nova-3-medical`, `deepgram-flux`, `deepgram-flux-multi`, `speechmatics`, `speechmatics-medical`, `whisper`, `gladia`, `xai`, `google-chirp-3`, `elevenlabs-scribe`, `assemblyai-universal-pro`, `gemini-transcribe-live`.
</ParamField>

<ParamField body="fallbackSttProvider" type="object">
Optional speech-to-text provider to fall back to. Same shape as `sttProvider`.
</ParamField>

<ParamField body="llmModel" type="string" default='platform-llm'>
Language model the agent uses to generate responses.

Defaults to `platform-llm`, the managed platform model. It is tuned for voice agents and kept current without any change to your configuration, and it is what agents created in the dashboard start on.

To pin a specific model instead, pass its id, for example `gpt-4.1` or `gemini-2.5-flash`. The models on offer change over time, so call [List Available Models](/v1/api-reference/endpoints/agents/call/list-models) for the current set rather than hardcoding one. A model that isn't on offer, or the retired `trillet-llm`, fails with `400`.
</ParamField>

<ParamField body="fallbackLlmModel" type="string">
Optional model to fall back to if the primary model fails. Checked the same way as `llmModel`.
</ParamField>

<ParamField body="smartCallback" type="boolean" default="false">
Enable smart callback functionality for the agent.
</ParamField>

<ParamField body="maxAttemptsForSmartCallback" type="number" default="5">
Maximum number of callback attempts when smart callback is enabled.
</ParamField>

<ParamField body="gapBetweenEachAttemptForSmartCallback" type="array">
Array of time intervals between each callback attempt. Each item contains days and hours. Defaults to five gaps of one day. An item outside the ranges below is reset to `{ "days": 1, "hours": 0 }`.

<Expandable title="Array Item Properties">

<ParamField body="days" type="number" default="1" min="0" max="30">
Number of days to wait before the next attempt.
</ParamField>

<ParamField body="hours" type="number" default="0" min="0" max="23">
Number of hours to wait before the next attempt.
</ParamField>

</Expandable>
</ParamField>

<ParamField body="type" type="string" default="voice">
`voice` or `chat`.
</ParamField>

<ParamField body="settings" type="object">
Voice and model tuning. Stored exactly as sent: the API applies no defaults, and if you leave it out it stays unset. The dashboard starts new agents on `{ "speed": 0, "volume": 1, "temperature": 0.3 }`.

<Expandable title="properties">

<ParamField body="speed" type="number">
Speaking speed. How the value is applied depends on the voice provider. `0`, or leaving it out, keeps the provider's normal speed. Tune it in the dashboard's voice settings if you need a specific pace.
</ParamField>

<ParamField body="volume" type="number">
Volume of the voice. The dashboard uses `1`.
</ParamField>

<ParamField body="temperature" type="number">
Creativity of the language model, from 0 to 1. The dashboard uses `0.3`.
</ParamField>

</Expandable>
</ParamField>

<Warning>
`phoneNumberIds` and `variables` are ignored on create. Attach numbers with [Assign Phone Number to Agent](/v1/api-reference/endpoints/telephony/bind-call-to-phoneNumber).
</Warning>

## Response

`200` with the saved agent.

<ResponseField name="_id" type="string">
Unique identifier for the newly created agent. Pass it as `agent` when you [create a call flow](/v1/api-reference/endpoints/flows/call-flows/create) to link the two. The agent then shows up inside that call flow and on the Phone Numbers page. An agent serves one call flow, so create a new agent for each flow.
</ResponseField>

<ResponseField name="workspaceId" type="string">
Workspace ID associated with the agent.
</ResponseField>

<ResponseField name="userId" type="string">
User ID of the agent creator.
</ResponseField>

<ResponseField name="name" type="string">
Name of the agent.
</ResponseField>

<ResponseField name="ttsModel" type="object">
Text-to-Speech configuration for the agent, as sent (`provider`, `voiceId`, `name`, `language`, `rimeModel`, `elevenLabsModel` and any BYO key fields).
</ResponseField>

<ResponseField name="fallbackTtsModel" type="object | null">
Fallback voice, or `null`.
</ResponseField>

<ResponseField name="sttProvider" type="object | null">
Speech-to-text provider, or `null`.
</ResponseField>

<ResponseField name="llmModel" type="string">
Language model used by the agent. `platform-llm` if you didn't send one.
</ResponseField>

<ResponseField name="fallbackLlmModel" type="string | null">
Fallback language model, or `null`.
</ResponseField>

<ResponseField name="smartCallback" type="boolean">
Whether smart callback is enabled for the agent.
</ResponseField>

<ResponseField name="maxAttemptsForSmartCallback" type="number">
Maximum number of callback attempts.
</ResponseField>

<ResponseField name="gapBetweenEachAttemptForSmartCallback" type="array">
Array of time intervals between callback attempts.
</ResponseField>

<ResponseField name="type" type="string">
`voice` or `chat`.
</ResponseField>

<ResponseField name="phoneNumberIds" type="array">
Always empty on a new agent.
</ResponseField>

<ResponseField name="activeSessions" type="array">
Array of active sessions for the agent.
</ResponseField>

<ResponseField name="settings" type="object">
Settings as sent, or absent if you didn't send any.
</ResponseField>

<ResponseField name="status" type="string">
`ready` for a new agent.
</ResponseField>

<ResponseField name="createdAt" type="string">
Timestamp when the agent was created.
</ResponseField>

<ResponseField name="updatedAt" type="string">
Timestamp when the agent was last updated.
</ResponseField>

## Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "Workspace ID is required"}` | No `x-workspace-id` |
| `400` | `{"message", "code": "TTS_MODEL_INVALID"}` | `ttsModel` is missing, or has no `provider` or `voiceId` |
| `400` | `{"message", "code": "LLM_MODEL_INVALID"}` | `llmModel` or `fallbackLlmModel` isn't an available model, or is the retired `trillet-llm` |
| `500` | `{"error": "..."}` | Anything else, including a `provider` or `sttProvider.id` outside the allowed list |
