---
title: "Update Call Agent"
api: "PUT /v1/api/agents/{agentId}"
description: "Update an existing agent"
---

Send only the fields you want to change. Objects such as `ttsModel` and `settings` are merged into what is stored; arrays such as `gapBetweenEachAttemptForSmartCallback` and `phoneNumberIds` replace the stored array.

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Path Parameters

<ParamField path="agentId" type="string" required>
The unique identifier of the agent to update.
</ParamField>

## Request Body

<ParamField body="name" type="string">
New name for the agent.
</ParamField>

<ParamField body="llmModel" type="string">
New language model for the agent. Omit it to leave the current one unchanged.

Pass `platform-llm` for the managed platform model, or a specific model id such as `gpt-4.1` or `gemini-2.5-flash`. The models on offer change over time, so call [List Available Models](/v1/api-reference/endpoints/agents/call/list-models) for the current set rather than hardcoding one.
</ParamField>

<ParamField body="ttsModel" type="object">
Text-to-Speech configuration updates.

<Expandable title="Voice Settings">

<ParamField body="provider" type="string" required>
The text-to-speech provider. One of `rime`, `openai`, `openai-live`, `elevenlabs`, `11labs_byo`, `cartesia`, `cartesia_byo`, `google`, `gemini-3.8-flash`, `gemini-3.8-flash-lite`, `azure`, `hume`, `xai`, `grok`, `deepgram`, `fish`. Custom voices from the [Voices API](/v1/api-reference/endpoints/voices/create) use `cartesia`. See [Create Call Agent](/v1/api-reference/endpoints/agents/call/create) for the other `ttsModel` fields (`rimeModel`, `elevenLabsModel`, BYO key and secret-name fields) and for `fallbackTtsModel`, `sttProvider`, `fallbackSttProvider` and `fallbackLlmModel`, which can also be updated.
</ParamField>

<ParamField body="voiceId" type="string">
The voice to speak with. Take it from the `voiceId` field of [Search Voices](/v1/api-reference/endpoints/voices/search) rather than hardcoding one. Trillet Voices (provider `rime`) look like `mistv3_wildflower`, `mistv3_brook` or `mistv3_violet`; send the matching `rimeModel` (for example `mistv3`) with them.
</ParamField>

<ParamField body="language" type="string">
Language code (e.g., en, fr).
</ParamField>

<ParamField body="elevenLabsApiKey" type="string">
ElevenLabs API key (required only when provider is "11labs_byo"). Will be encrypted and stored securely. Set to null to remove existing key.
</ParamField>

</Expandable>
</ParamField>

<ParamField body="smartCallback" type="boolean" default="false">
Enable smart callback functionality for the agent.
</ParamField>

<ParamField body="maxAttemptsForSmartCallback" type="number" default="5">
Maximum number of callback attempts when smart callback is enabled.
</ParamField>

<ParamField body="gapBetweenEachAttemptForSmartCallback" type="array">
Array of time intervals between each callback attempt. Each item contains days and hours.

<Expandable title="Array Item Properties">

<ParamField body="days" type="number" default="1" min="0" max="30">
Number of days to wait before the next attempt.
</ParamField>

<ParamField body="hours" type="number" default="0" min="0" max="23">
Number of hours to wait before the next attempt.
</ParamField>

</Expandable>
</ParamField>

<ParamField body="phoneNumberIds" type="array">
Replaces the agent's list of phone number IDs. Every new ID must be a number in this workspace, otherwise the request fails with `400`. This only edits the list: it doesn't route calls or set up the number. To put a number on the agent, use [Assign Phone Number to Agent](/v1/api-reference/endpoints/telephony/bind-call-to-phoneNumber) and [Unassign Phone Number from Agent](/v1/api-reference/endpoints/telephony/unbind-call-to-phoneNumber) instead.
</ParamField>

<ParamField body="settings" type="object">
Additional settings for the agent.

<Expandable title="properties">

<ParamField body="speed" type="number">
Speaking speed. How the value is applied depends on the voice provider. `0` keeps the provider's normal speed.
</ParamField>

<ParamField body="volume" type="number">
Volume of the voice. The dashboard uses `1`.
</ParamField>

<ParamField body="temperature" type="number">
Creativity of the language model, from 0 to 1. The dashboard uses `0.3`.
</ParamField>

</Expandable>
</ParamField>

<ParamField body="variables" type="object">
Custom variables to store for the agent.
</ParamField>

## Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "Workspace ID is required"}` | No `x-workspace-id` |
| `400` | `{"message", "code": "LLM_MODEL_INVALID"}` | A changed `llmModel` or `fallbackLlmModel` isn't an available model, or is the retired `trillet-llm` |
| `400` | `{"error", "code"}` | `phoneNumberIds` names a number from another workspace |
| `500` | `{"error": "Agent not found or does not belong to the workspace"}` | No agent with this ID in the workspace. This is currently a `500`, not a `404` |
| `500` | `{"error": "..."}` | Anything else, including a `provider` outside the allowed list |
