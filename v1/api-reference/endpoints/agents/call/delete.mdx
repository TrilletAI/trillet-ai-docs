---
title: "Delete Call Agent"
api: "DELETE /v1/api/agents/{agentId}"
description: "Delete an existing agent"
---

The agent is soft-deleted: it disappears from the API and the dashboard, and support can recover it.

<Warning>
Deleting an agent does not touch the call flow that uses it. That flow keeps pointing at the deleted agent and stops working. To remove a flow and its agent together, [delete the call flow](/v1/api-reference/endpoints/flows/call-flows/delete) instead.
</Warning>

### Headers  

<ParamField header="x-workspace-id" type="string" required>
  Workspace identifier for the API.
</ParamField>

### Path Parameters

<ParamField path="agentId" type="string" required>
  The unique identifier of the agent to delete
</ParamField>

### Response

`200` with the agent as it was just before it was deleted, in the same shape as [Get Call Agent](/v1/api-reference/endpoints/agents/call/get).

### Errors

| Status | Body | When |
| --- | --- | --- |
| `400` | `{"error": "Workspace ID is required"}` | No `x-workspace-id` |
| `404` | `{"error": "Agent not found or does not belong to the workspace"}` | No agent with this ID in the workspace, including one already deleted |
| `500` | `{"error": "..."}` | Unexpected server error |
