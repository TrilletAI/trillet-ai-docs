---
title: "Delete Call Disposition"
api: "DELETE /v1/api/call-dispositions/{id}"
description: "Cancel a contact's queued callback, or delete a finished record."
---

What happens depends on the record:

- **A callback is queued:** the callback is cancelled. The record is kept with `status: "cancelled"`.
- **The queued callback has already run:** the record is kept and marked `status: "completed"`.
- **No further attempts were due** (`currentAttempt` is `-1`, or no callback is queued): the record is deleted.

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
The record's `_id`, from [List Call Dispositions](/v1/api-reference/endpoints/call-dispositions/list).
</ParamField>

## Response Fields

<ResponseField name="message" type="string">
What happened: `"Job cancelled successfully"`, `"Job already completed."` or `"Record deleted successfully."`.
</ResponseField>

## Errors

| Status | Body | When |
|---|---|---|
| `400` | `{"error": "Workspace ID is required"}` | The `x-workspace-id` header is missing |
| `404` | `{"message": "No call-disposition found for id <id>."}` | No record with that ID exists in this workspace |

<ResponseExample>
```json
{
  "message": "Job cancelled successfully"
}
```
</ResponseExample>
