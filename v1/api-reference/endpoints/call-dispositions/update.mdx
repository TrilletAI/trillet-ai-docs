---
title: "Update Call Disposition"
api: "PUT /v1/api/call-dispositions/{id}"
description: "Move a contact's next smart callback to a new time."
---

This endpoint only reschedules the next callback. It can't change a record's status, outcome or notes.

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Path Parameters

<ParamField path="id" type="string" required>
The record's `_id`, from [List Call Dispositions](/v1/api-reference/endpoints/call-dispositions/list).
</ParamField>

## Request Body

The body is the new callback time on its own, **not** a JSON object. Send it as a JSON string with `Content-Type: application/json`, for example `"2026-12-01T10:00:00"`, or as plain text with `Content-Type: text/plain`.

- Format: `yyyy-MM-ddTHH:mm:ss`, with no offset. It is read as local time in the record's `timezone`.
- A time less than a minute away, or in the past, is moved to one minute from now.
- If the record has no callback queued (`jobId` is `null`), the new time is saved on the record but no call is placed.

## Response

The updated record, with the fields described in [Get Call Disposition](/v1/api-reference/endpoints/call-dispositions/get). `nextCallTime` and `currentTimeOfGivenTimezone` show the new schedule.

## Errors

| Status | Body | When |
|---|---|---|
| `400` | `{"error": "Workspace ID is required"}` | The `x-workspace-id` header is missing |
| `400` | `{"error": "dateTime is required in body"}` | The body is empty |
| `404` | `{"error": "Call disposition not found"}` | No record with that ID exists in this workspace |

<RequestExample>
```bash cURL
curl -X PUT https://api.trillet.ai/v1/api/call-dispositions/c5c5c5c5c5c5c5c5c5c5c5c5 \
  -H "x-api-key: YOUR_API_KEY" \
  -H "x-workspace-id: YOUR_WORKSPACE_ID" \
  -H "Content-Type: application/json" \
  -d '"2026-12-01T10:00:00"'
```
</RequestExample>
