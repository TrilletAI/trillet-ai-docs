---
title: "List Call Dispositions"
api: "GET /v1/api/call-dispositions"
description: "List call disposition records, newest first, with filters."
---

A call disposition record tracks one contact in a [batch call](/v1/api-reference/endpoints/calls/batch/overview) with smart callbacks turned on. See [Get Call Disposition](/v1/api-reference/endpoints/call-dispositions/get) for the record's fields.

## Headers
<ParamField header="x-workspace-id" type="string" required>
Workspace identifier for the API.
</ParamField>

## Query Parameters

All filters are optional and can be combined. Text filters ignore case.

<ParamField query="page" type="number" default="1">
Page number.
</ParamField>

<ParamField query="limit" type="number" default="50">
Records per page.
</ParamField>

<ParamField query="phoneNumber" type="string">
Records whose phone number contains this text.
</ParamField>

<ParamField query="batchId" type="string">
Records whose batch ID contains this text.
</ParamField>

<ParamField query="agentId" type="string">
Records for this agent ID. A value that isn't a valid ID matches nothing.
</ParamField>

<ParamField query="status" type="string">
Records with this exact status: `active`, `inactive`, `cancelled` or `completed`.
</ParamField>

<ParamField query="attempt" type="number">
Records whose `currentAttempt` equals this number. `-1` finds records with no further attempts.
</ParamField>

<ParamField query="disposition" type="string">
Records where any attempt had this outcome, written exactly as stored. Outcomes include `No Answer`, `Voicemail`, `Dead Air`, `IVR`, `Partial Complete: Call Back`, `Completed Call`, `Not Interested`, `Not Eligible`, `Call Transfer: Success`, `Call Transfer: Failure`, `Abusive Customer`, `Remove Number`, `Can't Understand`, `Disconnected Number`, `Invalid Number`, `Declined`, `Number Not Reached`, `System Error` and `Unknown Error`. Encode spaces and colons in the URL.
</ParamField>

<ParamField query="timezone" type="string">
Records whose timezone contains this text, for example `America/New_York` or `Sydney`. This is a filter: times in the response are not converted.
</ParamField>

<ParamField query="search" type="string">
Records whose phone number or batch ID contains this text. A full agent ID also matches that agent's records.
</ParamField>

## Response Fields

<ResponseField name="data" type="object">
<Expandable title="properties">
<ResponseField name="dispositions" type="array">
The records on this page, newest first. Each has the fields described in [Get Call Disposition](/v1/api-reference/endpoints/call-dispositions/get).
</ResponseField>

<ResponseField name="total" type="number">
Number of records that match the filters.
</ResponseField>

<ResponseField name="page" type="number">
Current page number.
</ResponseField>

<ResponseField name="limit" type="number">
Records per page.
</ResponseField>

<ResponseField name="totalPages" type="number">
Number of pages.
</ResponseField>
</Expandable>
</ResponseField>

## Errors

| Status | Body | When |
|---|---|---|
| `400` | `{"error": "Workspace ID is required"}` | The `x-workspace-id` header is missing |
